# 本番用アプリ進捗と再開地点

Last updated: 2026-09-30

## 現在の状態

- 作業ブランチ: `codex/production-foundation`
- 現行First Playableはタグとアーカイブ用ブランチへ固定済み。
- `apps/production` は独立したReact/Viteの起動基盤。ゲーム機能はまだ移植していない。
- 初回公開範囲は第1～3章のWeb/PWA。
- 検証: `npm run lint`、`npm run typecheck`、`npm run build:production` は成功。
- このチャットに6時間ごとの継続開発スケジュールを設定済み。実行時にこの文書を読む。

## 次に進める作業

1. 現行のマップ、移動、セーブ処理を読み、最初の縦切りに必要な最小仕様を決める。
2. 本番用ゲーム状態と保存スキーマを実装する。旧セーブとキーを分離する。
3. 最小マップで移動、新規開始、保存、再読込を実装し、実画面で確認する。
4. 縦切りの結果から並行作業に切れる境界と担当ファイルを記録する。

## 再開時の手順

作業開始時に `git status`、このファイル、`PLAN.md` を確認する。未コミット変更や他セッションの進行を尊重し、重複作業を避ける。完了した作業、検証結果、次の一手を毎回このファイルへ記録する。利用枠の制限で中断した場合は、次回の定期実行時にここから続きを行う。初回公開の完成条件を満たしたら定期実行を止める。

## 次に進める作業

1. 実機のタッチ長押し・画面切替・復帰を確認し、ブラウザ容量不足時の再試行表示を確認する。端末やブラウザが強制終了した場合は保存の保証がないため、通常の中断経路を優先して確認する。
2. ゲーム状態と保存スキーマの拡張境界、画面とゲームルール間のイベント契約を固定し、担当ファイルを記録する。
3. `SESSIONS.md` の開始条件を満たした後、マップ・素材、生活システム、生活UI、戦闘を別セッション・別ワークツリーで順に開始する。
4. 統合セッションで各変更を取り込み、通し操作と全体検証を行う。

## 再開時の手順

作業開始時に `git status`、このファイル、`PLAN.md`、`SESSIONS.md` を確認する。未コミット変更や他セッションの進行を尊重し、重複作業を避ける。完了した作業、検証結果、次の一手を毎回このファイルへ記録する。利用枠の制限で中断した場合は、次回の定期実行時にここから続きを行う。初回公開の完成条件を満たしたら定期実行を止める。

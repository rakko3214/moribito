# アクセシビリティQA

Status: Foundation Implemented

## 実装済み

- Web UIとPhaser主要HUDの文字拡大
- Web UIの高コントラスト表示と明確なキーボードフォーカス
- 戦闘予兆の色・太線・文章による三重表現
- 通常攻撃予兆は「回避 / 結界」、貫通攻撃予兆は「範囲外へ」と表示
- 振動、画面揺れ、反復演出、軽量演出を個別に設定
- 各設定を端末ごとに保存し、旧形式の保存値にも既定値を補完

## 実機確認項目

1. 360×640と390×844で文字拡大時にも主要操作が画面内へ収まる。
2. 高コントラスト時にタイトル、ポーズ、設定のフォーカス位置を識別できる。
3. 通常予兆と貫通予兆を色を見ず文章だけで判断できる。
4. 振動非対応端末、`prefers-reduced-motion`利用端末でも進行不能にならない。
5. 軽量演出で雨天・戦闘・鍛冶を連続実行してフレーム落ちを比較する。

正式フォント、正式アート、対象ブラウザ確定後に、スクリーンリーダー、色覚シミュレーション、200%拡大、外付けキーボードを含む最終QAを行う。

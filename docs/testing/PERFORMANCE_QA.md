# 低性能端末QA

Status: Monitoring Implemented

プレイ画面を表示している間だけ描画フレームを計測し、ポーズ画面へ平均FPSと低下時FPSを表示する。タブがバックグラウンドへ移った際の長い停止時間は測定から除外する。

| 判定 | 基準 | 対応 |
|---|---|---|
| 良好 | 平均52FPS以上かつ低下時42FPS以上 | 現在設定を維持 |
| 制限あり | 平均38FPS以上かつ低下時28FPS以上 | 軽量設定を案内 |
| 低性能 | 上記未満 | 軽量設定を強く推奨 |

「推奨軽量設定を適用」では、軽量演出ON、画面揺れOFF、反復演出軽減ONを一括設定する。自動変更はせず、プレイヤーが選択した場合だけ適用する。測定値は端末診断用であり、クラウドセーブやゲーム進行には保存しない。

正式アート導入後は、村、雨天、通常戦、ボス戦、料理、釣り、調合、鍛冶を各5分以上実行し、端末機種・ブラウザ・発熱状態とともに記録する。

# 開発用テストメニュー

Status: Implemented
Last updated: 2026-09-02

## 目的

First Playableの章進行や生活機能を、通常導線を壊さず短時間で反復確認する。開発サーバーでゲームを開始し、ポーズメニュー下部から利用する。

## プリセット

| プリセット | 開始場所 | 主な確認対象 |
|---|---|---|
| 第1章・帰郷 | 主人公宅敷地 | 導入と生活チュートリアル |
| 農業・建築・家畜 | 主人公宅敷地 | 自由耕作、作業台、建築、飼育 |
| 料理 | なごみ食堂 | 切る、火加減、混ぜる、盛り付け |
| 釣り | 川 | 投擲、魚の接近、本アタリ、捕獲 |
| 調合 | 診療所 | 回転速度・方向、品質判定 |
| 鍛冶 | 鉄火堂 | 結晶石制作、杖への装着 |
| 通常戦闘 | 神社参道 | 通常穢れ、予兆、浄化 |
| 第2章・化け蛙 | 古池 | ボス戦と章完了 |
| 第3章・淀みの大樹 | 淀みの大樹 | ボス戦、木霊の別れ、First Playable完了 |

生活・制作プリセットは十分な所持金と基本素材を持った状態で開始する。章プリセットは各ProgressionSystemが直前目的を認識できる正式なSaveData v1として生成する。

## セーブ隔離

- テスト開始後はヘッダーを「テスト中」と表示する。
- セーブボタンは「保存対象外」として無効化する。
- GameRuntimeから発生する自動保存要求はクラウドAPIへ送信しない。
- タイトルへ戻ると開発セッションを終了し、通常のクラウドセーブを読み直す。
- テストメニューは `import.meta.env.DEV` のときだけ描画し、本番ビルドから除外する。

## 完了条件

- 全プリセットが共有Zod Schemaを通過する。
- 第2章プリセットが `purify_bakegaeru`、第3章プリセットが `purify_tree` を返す。
- production buildの成果物にメニュー名とプリセット名が含まれない。

# 2026-09-23 先行版の保存・再開チェック

対象は第1〜3章、Web/PWA、端末内保存。リリース完成判定ではない。

## 実装

- Web Locks対応環境では保存・初期化を同一の排他ロックで処理し、別タブとの保存競合を防ぐ。
- 非対応環境はリビジョン検査へフォールバック。同時更新の原子性は保証しない。
- 別タブで初期化された保存データを、古いタブから書き戻すことを拒否。
- JSON破損時は日本語で案内し、元データを保持。
- 容量不足の保存失敗で直前の正常データが残ることを回帰テスト。
- タイトル画面に保存された年・季節を反映。第3章終了後に未収録の第4章から再開できると表示しない。

## 検証範囲と残件

保存ロックのユニットテストはAPIの使用と例外伝播の検査であり、実ブラウザの複数タブ競合テストではない。
実ブラウザでの同時保存、スマホ実機、PWA更新・オフライン通し、第1〜3章の実操作通し、ボス戦、施設の絵と当たり判定、専用UIの完成確認は引き続き必要。
全体の残件は PRODUCTIZATION_BACKLOG.md を参照する。

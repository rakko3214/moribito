# スマートフォンブラウザ互換性QA

Status: Automated Check Implemented
Last updated: 2026-09-02

## 起動時の自動診断

ブラウザ起動時と画面回転・通信状態変更時に、以下を診断する。

- WebGL: 非対応の場合はゲーム起動不可として理由を表示する。
- 端末内保存: `localStorage`へ書き込みできない場合はゲーム起動不可として理由を表示する。
- 通信状態: オフラインでもプレイを継続し、進行を端末へ保留する旨を表示する。
- 画面方向: タッチ端末の横画面ではプレイを妨げず、縦画面を推奨する。
- Web Audio・振動: 非対応でもプレイ可能とし、ポーズ画面へ対応状況を表示する。
- タッチ入力: `maxTouchPoints`を使い、タッチ端末かマウス端末かを表示する。

## 手動確認項目

1. 縦画面で起動し、回転後に横画面の推奨表示が現れ、縦へ戻すと消える。
2. 機内モードでオフライン表示が現れ、操作と端末内保留が継続できる。
3. 通信復帰時に復帰通知が5秒間表示され、手動セーブを実行できる。
4. ノッチ・Dynamic Island・ホームインジケーターと通知が重ならない。
5. ポーズ画面に通信・入力・画面方向・音声・振動の診断結果が表示される。
6. WebGLまたはサイトデータを無効化した環境で、理由と再読み込み操作が表示される。
7. 一度クラウド保存した後にAPIを停止し、端末キャッシュから同じ進行を未保存状態で再開できる。
8. プレイ中に通信を復帰させ、未保存または保存失敗状態から保存要求が一度自動実行される。
9. production previewを一度オンラインで開き、再訪時にオフラインでもアプリシェルが起動する。
10. Service Worker更新時に更新通知が表示され、「更新して再起動」で新しいWorkerへ切り替わる。

## 対応方針

- 推奨: 最新のiOS Safari、Android Chrome
- 縦画面を基本レイアウトとするが、横画面でも状態確認と再操作を可能にする。
- 音声・振動は補助フィードバックであり、非対応を進行不能条件にしない。
- WebGLと端末内保存はゲーム描画・安全なセーブに必要なため必須とする。

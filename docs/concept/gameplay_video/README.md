# ゲームプレイ・コンセプト動画

Status: Concept
Last updated: 2026-08-04

> この映像は2026-08-04時点の仕様を可視化したスナップショットである。2026-08-05に主人公の性別、戦闘要素の解放順、浄化操作が更新されたため、現在の正式仕様確認には `MASTER_GDD.md` と `systems/COMBAT.md` を使用する。

## 目的

現在の仕様から想定される一日のプレイ感を映像化し、ゲームの方向性に関する認識を確認する。

## 映像へ反映した確定仕様

- スマートフォン縦画面
- 見下ろし型の和風2Dフィールド
- 村、主人公宅、畑、神社、森がつながる生活圏
- ゲーム内時間で進む一日
- 成熟作物のスワイプ連続収穫
- 河童による水やり・水路支援
- 妖怪は主人公へ常時追従しない
- フィールドから専用画面を挟まず戦闘へ移行
- スライド移動、短いタップによる最寄り敵への通常攻撃
- 専用ボタンは妖怪札と結界
- 専用回避ボタンを設けない
- 少数の敵との戦闘
- 穢れを削った妖怪へ近づき、妖怪札ボタン長押しで浄化（動画制作時点の旧表現）
- 浄化は撃破ではなく、妖怪を元の状態へ戻す行為
- 村人と妖怪がそれぞれの生活場所で共存する

## 映像上の仮表現

次の要素は最終仕様ではなく、認識合わせのための仮デザインである。

- ピクセル密度、タイルサイズ、頭身、カメラ倍率
- 主人公、村人、妖怪、建物の最終デザイン
- UIの正確な位置、サイズ、アイコン
- 護身札と霊力の具体的な表示方法
- 攻撃、結界、浄化のエフェクトと所要時間
- マップ上の建物配置と距離

## シーン構成

1. 朝の村と生活圏
2. 畑での連続収穫と河童の水やり支援
3. 森での探索と穢れ妖怪との戦闘
4. 無力化した妖怪の浄化
5. 夕方の村と人・妖怪の共存

動画は静止画を用いたコンセプト・アニマティックであり、実際のゲーム動作を録画したものではない。

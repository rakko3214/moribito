# First Playable 実装状況

Status: Implemented Mock

最終更新: 2026-08-12

## 現在の到達点

First Playableの機能モックはPhase 8まで完了している。ニューゲームから第1章、第2章、第3章を進め、淀みの大樹を浄化して木霊を見送るところまで、同一のゲーム状態で通してプレイできる。

実装済みの範囲：

- スマートフォン縦画面とPC横画面、ドラッグ移動、キーボード移動
- 村、主人公宅、神社、森の往復と正しい入口へのスポーン
- 時間経過、睡眠、農業、日次成長、採取物の日次再出現
- 料理、釣り、調合、買い物、奉納、倉庫、村人依頼
- NPCの日課配置、会話、最低限の友情値
- 近接・遠距離・突進の通常穢れ、護身札、霊力、結界、浄化
- 第2章ボス「化け蛙」と第3章ボス「淀みの大樹」
- 陽太の手掛かり、木霊との遭遇、木霊を見送る第3章完了演出
- Google認証境界、ユーザー別クラウドセーブ、競合・失敗・保留セーブの復旧
- 中断、再読込、再ログインを想定した進行状態の復元

## 完成判定の自動検証

`FirstPlayableFlow.test.ts` で次の一連の導線を検証する。

1. ニューゲーム開始
2. 第1章の会話、帰宅、農業、採取、依頼、神社、初浄化
3. 第2章の釣り、料理、調合、奉納、神主への報告、化け蛙浄化
4. 第3章の陽太、森の手掛かり、木霊、淀みの大樹浄化、別れ
5. 完了状態の保存と、新しいGameRuntimeへの再読込

マップテストでは、全マップ遷移先と到着スポーンの対応も検査する。

## 「モック完了」に含まないもの

現在の完成判定は、仕様認識とゲームループを確認するための機能モックに対するもの。製品版品質としては、次が残る。

- 仮図形・仮マップから正式なドット絵、アニメーション、タイルマップへの置換
- 効果音、BGM、画面演出、会話演出の制作
- 仕様書にある作物、魚、料理、調合品、依頼、通常穢れの本数拡充
- 長時間の実機プレイによる操作感、難易度、経済、進行時間の調整
- AWS dev環境と複数実端末を使った最終クラウドセーブ検証
- アクセシビリティ、対応ブラウザ、低性能端末の最終QA

これらは機能モックの進行確認後に行う、コンテンツ制作・製品化工程として扱う。

# First Playable 実装状況

Status: Productization In Progress

最終更新: 2026-09-12

## 現在の到達点

First Playableの機能プロトタイプは第1～3章まで完了している。ニューゲームから第1章、第2章、第3章を進め、古池の再訪、淀みの大樹の浄化、神主への報告、祖父の手帳、木霊の歩み寄りまで、同一のゲーム状態で通してプレイできる。

## 正規品化の完成条件

機能が存在するだけでは完成と判定しない。次のすべてを満たした時点で、第1～3章のローカル完成版とする。

1. NPC、採取物、建物、家具、柵、家畜設備の見た目と当たり判定が一致する
2. 全16マップが最終地形、障害物、入口、目的地、採取地点、敵配置を持つ
3. 文字経路だけでなく、接続と目的地を視覚表示する正式地図UIを持つ
4. NPC会話と、料理、調合、鍛冶、釣り、買い物、建築の施設UIを明確に分離する
5. 各ミニゲームがスマートフォンのタップ、長押し、スワイプ、円運動、入力中断を安全に処理する
6. 通常戦闘と章ボスが障害物、敵配置、敗北、再挑戦、セーブ制御を含めて成立する
7. 360×640、390×844、PC横画面で全章を実画面確認し、全自動テスト、型検査、lint、本番ビルドが成功する

自動テスト成功だけを製品完成の根拠にはしない。操作感、視認性、当たり判定、難易度は実画面と実機相当入力で別途検証する。

## 完成判定の自動検証

`FirstPlayableFlow.test.ts` で次の一連の導線を検証する。

1. ニューゲーム開始
2. 第1章の会話、帰宅、農業、採取、依頼、神社、初浄化
3. 第2章の釣り、料理、調合、奉納、神主への報告、化け蛙浄化
4. 第3章の古池再訪、陽太、森の手掛かり、木霊、淀みの大樹浄化、神主への報告、祖父の手帳、木霊の歩み寄り
5. 完了状態の保存と、新しいGameRuntimeへの再読込

マップテストでは、全16マップの遷移先と到着スポーンの対応も検査する。通しテストでは目的地案内、マップ間経路、進行ゲートの解放順も同時に検証する。

## フェーズ別検証

- Phase 1: 時間帯・天候表示 — 単体テストと型チェック完了
- Phase 2: PC・スマートフォンHUD — レイアウト単体テストと型チェック完了
- Phase 3: 第1〜3章の通し進行 — 目的地・経路・進行ゲートを含む統合テスト完了
- Phase 4: 全体品質確認 — lint、型チェック、全テスト、production build、Docker・ブラウザ確認を完了条件とする

2026-09-12時点で、390×844および360×640のローカルブラウザ実画面を再確認した。スマートフォンでは状態詳細を初期状態で折り畳み、HUD、章目的、主要操作を画面内へ収める。コンソールエラー・警告なし、全自動テスト、型検査、lint、production build成功を確認済み。

## 製品版UI移行

妖怪札UIは仲間・札育成仕様を実装する段階まで保留する。先行して、スマートフォンで誤操作が起きやすかった生活行動を即時実行から確認・選択画面へ移行した。正式アート導入前のため外観は暫定だが、画面構造と操作フローは製品版へ引き継ぐ前提とする。

## 「モック完了」に含まないもの

現在の完成判定は、仕様認識とゲームループを確認するための機能モックに対するもの。製品版品質としては、次が残る。

- 仮図形・仮マップから正式なドット絵、アニメーション、タイルマップへの置換
- 効果音、BGM、画面演出、会話演出の制作
- 長時間プレイテストに基づくサブイベント発生時期・報酬・必要品の最終調整
- 長時間の実機プレイによる操作感、難易度、経済、進行時間の調整
- AWS dev環境と複数実端末を使った最終クラウドセーブ検証
- 正式フォント・正式アート導入後のスクリーンリーダー、対応ブラウザ、低性能端末の最終QA

これらは機能モックの進行確認後に行う、コンテンツ制作・製品化工程として扱う。

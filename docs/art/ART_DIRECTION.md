# アートディレクション

Status: Draft  
Last updated: 2026-07-29

## 基本方針

- 温かみのある和風ドット絵
- 見下ろし型2D
- スマートフォン縦画面で読みやすいシルエット
- 序盤は暖色と自然色を中心にする
- 物語進行と穢れにより、寒色、霧、暗部、赤い空などを段階的に増やす
- 特定作品のキャラクター、タイル、パレットを直接模倣しない

## 制作対象

- 主人公
- 村人約25人
- 妖怪
- 穢れ化差分
- 不可逆穢れ妖怪
- 動物
- 建物
- タイルセット
- 作物の成長段階
- 料理
- アイテム
- UI
- 戦闘・浄化エフェクト

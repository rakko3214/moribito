# Moribito 正式アート仕様

Status: In production
Last updated: 2026-09-05

## 基準

- ジャンルは日本の山村を舞台にした見下ろし型生活RPG。
- 手描きのピクセルアートとし、輪郭は硬く、縮小時にも形と役割を判別できること。
- 写実ではなく温かい32-bit時代風の密度を基準にする。
- 深緑、生成り、木材色を基調とし、物語上重要な対象だけ朱・金・穢れ紫で強調する。
- 画像内に文字、UI、ロゴ、透かしを含めない。

## 表示規格

- 主人公・成人NPC: マップ用ドット絵は32×48px前後を基準とする。体格差は横幅と高さの範囲内で表現する。
- 子ども・小型妖怪: 成人の70～85%。
- 通常敵: 主人公の90～140%。ボスは180～300%。
- 会話用立ち絵とマップ用ドット絵は別ファイルで管理する。立ち絵のリアルタイム縮小をマップ表示へ使用しない。
- キャラクター画像は透過PNGで保存し、マップ用ドット絵は足元を原点として配置する。
- 当たり判定は画像全体ではなく足元周辺に限定する。
- キャラクターの向き、歩行、作業、被弾は同一デザインからスプライトシート化する。

## キャラクター基準: 主人公

- 若い結師。性別を強く固定しない親しみやすい外見。
- 深緑の作業羽織、生成りの肌着、濃色の裁着袴、朱の組紐、草履。
- 腰に小さな木札を持つが、通常時は武器を構えない。
- 会話用立ち絵は `player-main-v1.png`、マップ用ドット絵は実寸32×48pxの正面 `player-field-v1.png`、背面 `player-field-back-v1.png`、横向き `player-field-side-v1.png` を使用する。左向きは横向きを反転表示する。
- 歩行は各方向の静止フレームと `player-walk-down-v1.png`、`player-walk-up-v1.png`、`player-walk-side-v1.png` の踏み出しフレームを140ms間隔で交互表示し、停止時は即座に静止フレームへ戻す。
- 正式アニメーション制作時も顔、髪、衣装色、朱の組紐を同一に保つ。

## キャラクター基準: 志希

- 主人公と同年代の幼なじみで、序盤の農業案内役。
- 茶色の短髪、藍の作務衣、生成りの前掛け、苔色の裁着袴、草履。
- 主人公より柔らかく生活感のある配色にし、朱の組紐と深緑の羽織は使用しない。
- `npc-shiki-v3.png` は会話用立ち絵の基準とする。
- マップ用は主人公と同じ 32×48 px 規格の `npc-shiki-field-v1.png`（正面）、`npc-shiki-field-back-v1.png`（背面）、`npc-shiki-field-side-v1.png`（横向き）を使用する。左向きは横向きを反転して表現する。
- 歩行差分は `npc-shiki-walk-down-v1.png`、`npc-shiki-walk-up-v1.png`、`npc-shiki-walk-side-v1.png` を使用し、待機姿勢との2コマで歩行を表現する。
- 主人公との差別化として、細い榛色の目、太い直線的な眉、丸く広い頬、農作業の日焼け、そばかす、片側が上がる口元、横へ流した前髪を維持する。

## キャラクター基準: 楓

- 38歳のなごみ亭店主で、しきの母。村のみんなを迎える母親役。
- 成熟した丸い輪郭、琥珀色の目、目尻の笑い線、緩やかな眉、低いまとめ髪で若者2人と区別する。
- 楓色の小袖、白い割烹着、焦茶の仕事袴、白足袋を着用し、腰のお玉を料理人の識別点とする。
- しきとの家族的共通点は暖かな肌色と茶色い髪に限定し、顔の部品と髪型は共有しない。
- `npc-kaede-v1.png` は会話用立ち絵の基準とする。
- マップ用は32×48 px規格の `npc-kaede-field-v1.png`（正面）、`npc-kaede-field-back-v1.png`（背面）、`npc-kaede-field-side-v1.png`（横向き）を使用する。左向きは横向きを反転して表現する。
- 歩行差分は `npc-kaede-walk-down-v1.png`、`npc-kaede-walk-up-v1.png`、`npc-kaede-walk-side-v1.png` を使用し、待機姿勢との2コマで歩行を表現する。

## キャラクター基準: 鉄斎

- 48歳の鉄火堂店主。神具、結晶石、精錬を担う、無口で信頼の厚い鍛冶職人。
- 四角く日焼けした輪郭、奥まった灰色の目、太い直線的な眉、幅広い鼻、白髪交じりの短髪で他の村人と区別する。
- がっしりした体格を成人NPCの基準より横へ広く取り、腕まくりした墨色の作務衣、錆茶の厚手前掛け、藍の手ぬぐいを着用する。
- 腰の大金槌を鍛冶屋の識別点とし、通常時は攻撃姿勢ではなく落ち着いて立つ。
- `npc-tessai-v1.png` は会話用立ち絵の基準とする。
- マップ用は32×48 px規格の `npc-tessai-field-v1.png`（正面）、`npc-tessai-field-back-v1.png`（背面）、`npc-tessai-field-side-v1.png`（横向き）を使用する。横幅を成人NPCの上限近くまで使い、がっしりした体格を表現する。
- 歩行差分は `npc-tessai-walk-down-v1.png`、`npc-tessai-walk-up-v1.png`、`npc-tessai-walk-side-v1.png` を使用する。金槌は腰へ固定し、歩行中も攻撃姿勢にしない。

## キャラクター基準: 源三

- 56歳の漁師で、釣りの案内役と河童の物語への橋渡し役。
- 川風に焼けた細身で丈夫な体格、白髪混じりの短髪、笑い皺のある豪快な笑顔で鉄斎と区別する。
- 藍の鉢巻き、褪せた青緑の仕事着、生成りの肌着、濃藍の袴、苔色の胴長靴を着用する。
- 釣り竿と腰の魚籠を識別要素とし、亡き妻の形見である小さな赤い布飾りを魚籠へ結ぶ。
- `npc-genzo-v1.png` を会話用立ち絵の基準とする。
- マップ用は32×48 px規格の `npc-genzo-field-v1.png`（正面）、`npc-genzo-field-back-v1.png`（背面）、`npc-genzo-field-side-v1.png`（横向き）を使用する。左向きは横向き画像を反転して使用する。
- 歩行差分は `npc-genzo-walk-down-v1.png`、`npc-genzo-walk-up-v1.png`、`npc-genzo-walk-side-v1.png` を使用する。釣り竿と魚籠は身体へ固定し、移動中も戦闘姿勢にしない。

## キャラクター基準: 神主

- 40代後半の細身の神職。第1～3章では信頼できる案内役に見えることを優先し、黒幕性を外見で露骨に示さない。
- 黒髪交じりの灰色の結髪、黒い烏帽子、白・生成りの狩衣、落ち着いた朱の袴、木製の笏を識別点とする。
- `npc-kannushi-v1.png` を会話用立ち絵、`npc-kannushi-field-*.png` と `npc-kannushi-walk-*.png` を32×48pxの方向別・歩行表示へ使用する。

## キャラクター基準: 宗一郎

- 58歳の村長。広い肩、撫で付けた灰髪、短い口髭、疲れを含む温かな目で、責任を背負う人物として表現する。
- 墨色の着物と袴、苔色の羽織、木製の村長札を識別点とし、悪人に見せない。
- `npc-soichiro-v1.png` を会話用立ち絵、`npc-soichiro-field-*.png` と `npc-soichiro-walk-*.png` を32×48pxの方向別・歩行表示へ使用する。

## キャラクター基準: 宗玄

- 62歳の薬師。白い結髪、丸眼鏡、短い白髭、生成りの和装白衣、深緑の襟、木製薬箱を識別点とする。
- `npc-sogen-v1.png` を会話用立ち絵、`npc-sogen-field-*.png` と `npc-sogen-walk-*.png` を32×48pxの方向別・歩行表示へ使用する。

## キャラクター基準: 陽太

- 8歳前後の妖怪好きな少年。丸い頬、大きな榛色の目、跳ねた栗色の短髪、山吹色の羽織、藍の肌着、木の実入りの肩掛け袋を識別点とする。
- `npc-yota-v1.png` を会話用立ち絵、`npc-yota-field-*.png` と `npc-yota-walk-*.png` を成人より小さい実像を含む32×48pxキャンバスへ使用する。

## 妖怪・敵基準

- 通常穢れは `kegare-remnant-v1.png`（48×48px）。人格や種族を連想させない黒紫の非対称な残滓とし、浄化対象であることを紫の核で示す。
- 河童は `kappa-field-v1.png`（40×40px）。丸い緑の体、頭の水皿、小さな甲羅、きゅうりで、寂しがりだが親しみやすい性格を示す。
- 穢れ化・化け蛙は `bakegaeru-corrupted-v1.png`（96×96px）。苦しむ古池の蛙を黒紫の穢れが覆い、悪意ではなく暴走状態に見せる。
- 木霊は `kodama-field-v1.png`（40×48px）。木肌の身体、仮面状の顔、若葉と苔で善良な自然妖怪として表現する。
- 淀みの大樹は `yodomi-tree-v1.png`（180×210px）。顔や手足を付けず、普通の大木の一部を穢れが侵食した被害対象として表現する。

## 環境テクスチャ基準

- 主人公宅敷地は `homestead-grass-v1.png`、村と屋外生活圏は `village-grass-v1.png` を敷く。
- 主人公宅と主要施設内は `interior-tatami-v1.png`、神社参道と境内は `shrine-stone-v1.png` を共通基礎床とする。
- 川・古池は `river-water-v1.png`、森・森深部・大樹の木立は `forest-floor-v1.png` を基礎地面に使用する。
- 地面画像は256×256pxへ整形し、反復表示する。建物、岸、樹木、家具などは別レイヤーへ置き、当たり判定を画像へ直接埋め込まない。
- 村の雑貨屋、なごみ亭、鉄火堂、診療所、村長宅は `village-*-v1.png`、神社拝殿は `shrine-main-hall-v1.png` を使用し、既存Object Layerの建物当たり判定と扉位置へ合わせる。
- なごみ亭、雑貨屋、鉄火堂、診療所、村長宅、漁具小屋の設備群は `interior-*-v1.png` として分離し、畳地面、NPC、操作設備、当たり判定より背面へ配置する。
- NPCには静止画像を変形しすぎない微細な待機呼吸、穢れ・章ボスには状態を読み取りやすくする緩やかな脈動を付ける。演出軽減が有効な場合は停止する。
- フィールド表示は32×48pxの画像キャンバスをそのまま同寸表示せず、足元基準を固定したうえで年齢・体格別の表示寸法を適用する。若者は34×51px前後、成人は38×57px前後、大柄な成人は40×58px前後、子どもは29×43px前後とする。
- 参道は `shrine-torii-v1.png` と `shrine-lantern-pair-v1.png`、川は `river-fishing-hut-v1.png` と `river-bank-v1.png`、森は `forest-grove-v1.png`、古池は `old-pond-bank-v1.png` を独立オブジェクトとして配置する。
- 農業と採取の操作成功時は、対象地点から道具・行動に対応する色の輪と粒子を短時間だけ表示する。演出軽減時は省略し、操作結果の文章表示は維持する。
- `farm-crops-resources-v1.png` を農業用スプライトシートとして使用し、発芽・若葉・成長・収穫可能の4段階を表示する。
- 大根・きゅうりは `farm-crops-resources-v1.png`、人参・なす・かぼちゃ・米は `farm-crops-expanded-v1.png` の専用形状を使い、全6作物を形でも判別可能にする。
- 水やり済みの状態は作物色ではなく、畝の縁を青くして伝える。
- `field-gathering-nodes-v1.png` は、よもぎ・森きのこ・山菜・川藻・清水・霊木の実と、第3章の追跡手掛かりをフィールド上で区別するために使う。
- 手採取素材は32～48px相当を基本とし、清水だけは水場として少し大きく表示する。
- `placeable-craftables-v1.png` は作業台で制作する家具・柵・家畜設備・看板の8種に使用する。
- `placeable-farm-buildings-v1.png` は大工へ依頼する鶏小屋・家畜小屋・温室に使用し、配置グリッドの占有範囲より上方向へ建物が立ち上がって見えるよう表示する。
- 配置プレビューは完成時と同じ画像を半透明で表示する。占有範囲を設置可能時は緑、不可時は赤で示し、画像自体にも同系色を薄く重ねる。
- `livestock-states-v1.png` は鶏と牛の幼体・成体・給餌済み・生産物回収可能を表し、対応する飼育施設の手前へ表示する。
- 生産物回収可能時は黄色の `!`、給餌済みは桃色のハートを添え、色だけでなく記号でも状態を伝える。
- `field-tool-actions-v1.png` は鍬・斧・ピッケル・じょうろ・手採取・収穫の操作成功時に対象地点へ短く表示する。
- 道具画像は振り始めから接触方向へ約50度回転し、既存の輪・粒子と同時に消える。演出軽減時は一式を省略する。
- `home-interior-stages-v1.png` は主人公宅の初期・修繕後・最終増築後の3段階を表す。背景に家具は描き込まず、南側中央の出入口だけを全段階で固定する。
- 寝床・作業台・収納を含む室内家具は配置物用スプライトとして表示し、プレイヤーが回収・再配置できる。

## 制作順

1. 第1章: 主人公、志希、楓、鉄斎、源三、神主、村長、通常穢れ
2. 第1章: 主人公宅敷地、村、施設内装、神社参道、神社
3. 第2章: 宗玄、河童、化け蛙、川、古池
4. 第3章: 陽太、木霊、淀みの大樹、森、森深部
5. 全キャラクターの移動・生活・戦闘・イベントアニメーション

生成原画はそのまま最終決定とせず、ゲーム内の実寸表示、輪郭、色差、当たり判定を確認してから正式採用する。

# 正式決定事項

Status: Approved  
Last updated: 2026-08-04

## ゲーム

- ストーリー重視の和風生活ファンタジーRPGとする。
- スマートフォン向け、Android・iPhone対応、縦画面固定とする。
- フィールドは見下ろし型とし、画面を押しながらスライドして移動する。
- 固定表示の仮想スティックは使用しない。
- 戦闘はフィールド上のシームレス・セミオートアクション方式とする。
- 生活70%、戦闘30%を目安とする。
- 恋愛要素は採用せず、友情を中心にする。
- ゲーム内の役職名およびタイトルは「結師（ゆいし）」とする。

## 主人公

- 外見タイプを選択でき、能力・物語差は設けない。
- 初期名を用意し、名前を1～8文字程度で変更可能にする。
- 外見は髪型、髪色、肌色などの簡易カスタマイズとする。
- 顔パーツを細分化する本格的なキャラクタークリエイトは採用しない。
- 服装はゲーム内で入手・変更できる。
- 主人公は選択肢で意思を示す半無口型とする。
- 主人公は20歳前後で、進学または就職のため村を離れていた。
- 物語開始時点では戦闘経験がない。
- 幼少期に祖父の村を訪れ、妖怪らしき存在を見た曖昧な記憶がある。
- ゲーム開始時は「妖怪は人に害をなす悪い存在」だと信じている。
- 最初は結師の一時的な代理となり、物語を通じて自ら正式な結師になることを選ぶ。

## 物語

- 祖父は先代の結師であり、物語開始前に行方不明になる。
- 祖父は生存している。
- ゲームは祖父失踪を知らせる手紙から始まる。
- 主人公は祖父の家と畑を管理するため村へ戻る。
- 親友が最初のナビゲーターとして、移動、会話、家、農業、採取、納品、村人への挨拶を案内する。
- チュートリアル条件を満たして神社へ向かうが、神社には誰もいない。
- 神社からの帰り道で初めて妖怪を目撃し、村長と神主が一緒に現れる。
- 初戦闘は必勝のチュートリアル戦とする。
- 初戦闘後、主人公は結師の代理となり、神主から結札を受け取る。
- 親友から神主へメインナビゲーターが交代する。
- 神主は序盤から中盤までナビゲーターを務める。
- 結札から神主へ相談し、現在の目的と段階的なヒントを得られる。
- 神主はお告げを改ざんし、主人公を誘導する。
- 現神主は数百年続く神主一族の子孫で、初代神主の意思を継いでいる。
- 現神主は第10章の主要な敵であり、最終黒幕ではない。
- 初代神主本人は妖怪から奪った霊力によって数百年間生き続けている。
- 初代神主は既存の穢れを集め、増幅し、操ることができるが、無から生み出すことはできない。
- 初代神主の目的は神に代わって世界を支配することである。
- 初代神主は復活するのではなく、現神主の撃破後に表舞台へ姿を現す。
- 村長は神主に利用されており、悪意から妖怪への恐怖を広めたわけではない。
- 祖父の手帳は物語進行に伴って読める範囲が増える。
- 手帳を読むプレイヤーは神主への違和感に早く気付ける。
- 物語は全12章を基準とする。
- 第4～6章で妖怪を助け、共闘し、味方となる過程を描く。
- 第10章で現神主、第11～12章で初代神主と対決する。
- 結末では人間と妖怪が昔のような共存を再開する。
- 神は最後まで姿を見せず、声だけで主人公を認める。

## 結師

- 「結師」は「ゆいし」と読む。
- 序盤では「結界を維持し、妖怪を退け、村を守る者」と説明される。
- 本来は「人と妖怪の縁を結び、双方の均衡を守る者」である。
- 「結」を結界と結びのダブルミーニングとして物語の中心に置く。
- 結師は歴代へ受け継がれる役目だが、血筋で自動継承されない。
- 結師を選ぶのは神であり、神主ではない。
- 神は心優しい者を結師として選ぶ。
- 正式な継承には、人間と妖怪の双方との関わりと本人の選択が必要である。

## 妖怪

- 村人は妖怪の存在を信じているが、姿を見ることができない。
- 見えないことへの恐怖から、災いを妖怪のせいだと考えている。
- 結師は妖怪を見ることができる。
- 神主も妖怪を見ることができるが秘密にしている。
- 人の穢れが薄れ、妖怪を受け入れた人物は徐々に妖怪を認識できる。
- 妖怪はペットではなく、地域で暮らす住人として扱う。
- 妖怪は自然の霊力と、人間の記憶・想い・感謝によって存在を保つ。
- 忘れられた妖怪は弱まり、最終的に存在が消える。
- 負の感情に侵された妖怪が穢れとなり、人間・妖怪・環境へ害を与える。
- 妖怪を自然妖怪、里妖怪、神格妖怪の生態・立場と、善良、中立、浄化可能な穢れ化、不可逆穢れ化の状態で整理する。
- 一部の善良・中立妖怪には浄化可能な穢れ化形態がある。
- 前半は自然妖怪の浄化可能な穢れ化を中心とする。
- 中盤以降は神格妖怪も穢れ化し、浄化に特別な条件を必要とする。
- 終盤には完全に穢れへ飲まれ、浄化できず討伐が必要な個体も登場する。
- 主要妖怪は、座敷童子、河童、天狗、妖狐、木霊、鬼、白蛇、雪女の8体とする。
- 準主要妖怪は、狸、鎌鼬、一反木綿、提灯お化け、ぬりかべ、ろくろ首、小豆洗い、山姥、猫又、化け蛙、火車、輪入道の12体とする。
- 神格妖怪は5体前後、不可逆穢れ妖怪は5～8体、穢れ化差分は10～15体を目安とし、妖怪帳全体は40～45枠とする。
- 主要妖怪は全員が専用ストーリー、友好度Rank、妖怪札、立ち絵、フィールドスプライトを持つ。
- 主要妖怪はメインストーリーで仲間になり、仲間加入後に友好度イベントを開始する。
- 友好度イベントは過去の説明だけでなく、仲間になってから育つ絆を中心に描く。
- 主要妖怪はそれぞれ固有の心のテーマと欠けた部分を持ち、主人公との交流による内面的な変化を描く。
- 主要妖怪の加入時に、友好度Rank ★1、妖怪札、妖怪帳、生活行動、季節イベント対象、固有支援をまとめて解放する。
- 友好度Rank上昇に合わせ、主人公の近くでの行動、村の散歩、他者との交流、支援、固有の日常行動を段階的に増やす。
- 座敷童子は最初から味方だった特別枠とし、通常加入ではなく記憶回復後に関係を取り戻す。
- 妖狐は普段は子狐の姿とし、人型は友好度Rank ★5で信頼の証として初公開する。以後も人型は特別なイベントに限定する。
- 妖狐の妖怪札は「狐火」1種とし、★1の単発、★2の追尾、★3の火球・範囲強化、★4の燃焼、★5の着弾爆発へ成長する。
- 座敷童子の妖怪札は「守護・幸運」をコンセプトとし、★1「福運」の移動速度上昇、★2「守り鈴」の被弾1回無効、★3「福招き」のドロップ率上昇、★4「幸結界」の護身札1枚復活、★5「家守りの祝福」の一定時間完全無敵へ成長する。
- 河童の心のテーマは「承認」とし、忘れられる恐れからいたずらをしていた状態から、人を笑顔にする喜びを知る物語とする。
- 河童の妖怪札は「水流」1種とし、★1の水弾、★2の貫通、★3のサイズ・速度強化、★4の水しぶき、★5の渦潮へ成長する。
- 準主要妖怪は地域イベントとサブクエストを基本とし、妖怪札と友好度Rankは必要な個体に設定する。
- 妖怪本体を主人公へ常時追従させる連れ歩きは採用しない。妖怪は各地域で暮らしながら生活・探索・移動・物語を支援し、戦闘では妖怪札発動時のみ幻影や演出を表示する。

## 主要キャラクター

- 親友は主人公が選択した外見タイプと同性で、同年代の幼なじみとする。
- 親友は農家の子どもで、恋愛対象ではなく最後まで味方となる。
- 座敷童子は妖怪側の主要人物で、主人公の幼少期の友人とする。
- 座敷童子は祖父の依頼を受け、自身の能力で主人公の妖怪に関する記憶を封印した。
- 座敷童子は封印を守るため、物語後半まで主人公と直接会話せず、陰から助ける。
- 結師と神主は妖怪を視認でき、子どもも座敷童子を一時的に見ることがある。
- 現神主は座敷童子の存在を知っているが、居場所を特定できない。

## ワールド

- ワールドはオープンワールドではなく、物語に応じて地域が増える段階開放型とする。
- 基本地域は、結の村、森、川、山、妖怪の里、神域、穢れの神殿とする。
- 妖怪の里は一つに限定せず、地域ごとに点在させる。
- ファストトラベルは妖怪との友情と物語進行によって解放する。
- 共存度を、人間社会と妖怪社会の信頼関係を示す全体指標として設ける。
- 共存度は村の変化、交流イベント、穢れ、最終決戦の支援、エピローグへ影響する。
- 共存度が低いことだけを理由に本編を完了不能にはしない。

## 生活

- 作物はリアル時間ではなくゲーム内時間で成長する。
- 成熟作物はタップまたはスワイプで連続収穫できる。
- 収穫操作の失敗で収穫量を減らさない。
- 生の作物は神社へ直接奉納せず、料理を奉納する。
- 妖怪の好物も原則として料理とする。
- 料理はASMR、癒やし、短いタッチ操作のミニゲームにする。
- 初回調理では工程を遊び、2回目以降はおまかせ調理を選択可能にする。

## 戦闘

- 非戦闘時は対象付近の長押しで会話・採取・調査を行う。
- 戦闘中は短いタップで通常攻撃を行う。
- 通常攻撃は最も近い敵へ自動で方向補正し、手動ロックオンは設けない。
- 画面を押している間は360度自由に方向転換でき、移動による位置取りを主な回避手段とする。
- 専用の回避ボタンは設けない。
- 戦闘用の専用ボタンは妖怪札と結界の2つを基本とする。
- 通常攻撃は1タップ1攻撃とし、長押し自動攻撃、溜め攻撃、必須の段階コンボは設けない。
- 神具と護符は同じタップ操作を使い、近距離では神具、射程外では護符へ自動で切り替える。
- 神具は複数種類から1つを装備し、ランダムに拾い替えず、入手・作成・強化して使う。
- 敵の索敵範囲へ入る、敵に発見される、または敵を攻撃すると戦闘状態へ移行する。
- 周囲の敵をすべて解決するか、一定時間敵が主人公を見失うと戦闘終了する。
- 妖怪本体を戦闘へ同行させない。
- 仲間になった妖怪から1体を選び、その力を宿した妖怪札を1枚装備する。
- 妖怪1体につき専用の妖怪札は1種類とする。
- 妖怪札は対象妖怪と友好化し、友好度Rank ★1となった時点で解放する。
- 妖怪札は常時効果、自動効果、霊力を消費する札技を持つ。
- 友好度は内部ポイント、友好度Rankは★1～★5として別管理する。
- 必要友好度へ到達した翌日、頭上に「！」が付いた妖怪へ話しかけ、専用の絆イベントを完了するとRankが上がる。
- イベントは保留でき、消滅しない。イベント待機中の友好度はRank上限で停止する。
- 会話による友好度上昇は1日1回、プレゼントは妖怪1体につき1日1回とする。
- 友好度Rankにより同じ固有能力の挙動と追加効果を、素材強化により基礎性能と強化上限を成長させる。
- 友好度Rank ★5の名称は「結び」とする。
- 妖怪札にレア度、重複入手、ガチャ、限界突破、強化失敗を設けない。
- 妖怪札は自宅、神社、安全な拠点、出発前画面、ダンジョン内の安全地点で変更できる。
- 妖怪札の役割は攻撃、防御、支援、妨害、探索の内部分類とし、ゲーム内へカテゴリ名を表示しない。
- 妖怪札は札ごとに消費霊力とクールタイムを持つ。
- 妖怪札と敵には火、水、雷、木、風、光、闇の属性を設定する。
- 火・水・雷・木は循環相性、風は汎用、光と闇は相互弱点とする。
- 火傷、濡れ、感電、束縛、吹き飛ばし、浄化、呪いの属性効果を導入する。
- 霊力は敵を倒す、または穢れを削ることでドロップし、近づくと自動回収する。
- 霊力は時間経過、通常攻撃の命中、ドロップ回収、浄化、一部料理でも回復する。
- 戦闘中の素材・霊力は近づくだけで吸引・回収できる。
- 戦闘終了時は取得可能な未回収ドロップを自動回収する。
- 被弾時はノックバックと短い無敵時間を設け、通常敵では長時間ダウンさせない。
- ボス戦は専用BGM、HPバー、結界、攻撃予告、専用ギミックを持つ。
- 結界はボタンを押している間だけ展開し、発動時と維持中に霊力を消費する。展開中も移動できる。
- 結界は独立した耐久を持ち、耐久0で破壊される。耐久低下は色とひび割れで表示する。
- 通常攻撃とノックバックは結界で防げるが、呪い、特殊な穢れ、神格妖怪の特殊攻撃、ボスギミックには結界貫通を設定できる。
- 敵の攻撃は地面範囲、予備動作、効果音で予告し、移動回避・結界防御・どちらでも対応可能の3種類に分ける。
- 一般的なHPは、耐久を持つ複数枚の護身札として表現する。
- 護身札は初期3枚とし、原則としてどの攻撃でも1回の被弾につき1枚失う。
- 通常攻撃で同時に複数枚は失わず、明確に予告された大技やギミックだけを例外とする。
- 護身札は料理、神社、自宅、一部妖怪札で回復する。
- 戦闘中の料理メニューと一時停止メニューでは戦闘を停止する。
- 料理ごとに護身札の回復枚数を設定し、戦闘へ持ち込める個数に上限を設ける。
- すべての護身札が破れると神社または自宅で目覚め、時間経過、霊力0、所持金少量減少を適用する。
- 戦闘不能時にアイテム、装備、妖怪との友情は失わない。
- 浄化可能な敵は穢れを削り切ると無力化し、近距離で妖怪札ボタンを長押しすると浄化を開始する。
- 浄化中の被弾で中断し、浄化不可の敵には浄化操作を表示しない。
- 序盤および妖怪札未装備時は、霊力を消費しない護符の遠距離通常攻撃を使用する。
- 神具による近接攻撃、妖怪札、結界、浄化能力はメインクエストで段階的に解放する。
- 独立した結術システムは採用せず、主人公固有の戦闘能力は結界と浄化、攻撃属性と特殊効果は妖怪札が担う。
- 主人公の成長は結師Rankを軸とし、護身札、神具、霊力上限、結界、浄化能力を強化する。
- 神具は複数の祭具から1つを選び、武器の拾い替えを中心にせず強化して使用する。
- お守りをビルド要素とし、装備枠は2～3枠を暫定案とする。

## 妖怪交流

- 妖怪ごとに時間帯、季節、天候、イベント進行に応じた生活リズムを持たせる。
- Rank、季節、天候、イベント進行に応じて会話を追加する。
- 好物は会話、村人の噂、妖怪帳、実際に渡した反応から判明する。
- 妖怪帳は遭遇、友好化、Rankアップに応じて情報と主人公コメントを解放する。
- 全対象妖怪の★5達成を長期的なやり込み目標とする。

## 時間

- 1日は6:00に開始し、翌日2:00に強制就寝する。
- 通常フィールドでは一定速度で時間を進める。
- 内部時刻は1分単位、UIは原則5分刻みで扱う。
- 会話、メニュー、店、イベント、ロード、ミニゲーム本編、演出中は時間を停止する。
- 現実のミニゲーム所要時間はゲーム内時間へ影響させない。
- ミニゲーム終了後に、個別仕様で定めた時間をまとめて加算する。
- 成功・失敗・開始後の中断にかかわらず、原則として規定時間を消費する。
- 農業の連続収穫など、時間を消費しないミニゲームを設定可能にする。
- 2:00を超える作業の開始を許可し、結果確定後に強制就寝する。
- 強制就寝では所持金やアイテムを失わず、翌日のスタミナ回復低下と穢れ少量増加を適用する。
- 設備、能力、妖怪との友情等による時間短縮と、最小消費時間を設定可能にする。
- 時間を完全停止するアイテムは採用しない。
- 初期実装はシングルプレイ専用とする。
- ファストトラベルは時間を消費し、妖怪との友情によって移動時間を短縮できる方向性とする。

## アート

- オリジナルの和風ドット絵を採用する。
- 特定作品の素材やキャラクターデザインを直接再現しない。
- フィールドキャラクターは4方向対応の2Dスプライト、会話は表情差分付き立ち絵とする。
- Live2Dは採用せず、重要イベントのみ一枚絵や専用演出を用いる。
- キャラクターのピクセル寸法、頭身、タイル寸法、表示倍率はスマートフォン実機のプロトタイプ確認後に確定する。
- 小規模なAWS公開を前提に、スプライトシート、左右反転、共通アニメーション、アセット再利用、必要時読み込みを優先する。

# PWA・オフライン起動仕様

Status: Implemented; production browser/device QA pending
Last updated: 2026-09-23

## 対応範囲

- Web App Manifestによるホーム画面追加
- `standalone`表示と縦画面優先
- Android系対応ブラウザのインストールプロンプトをタイトル画面へ表示
- Service Workerによるビルド単位のアプリシェル・全配信アセットの事前キャッシュ
- 新しいService Worker待機時の更新通知と安全な再起動
- アカウント不要の端末内保存（サーバー再送・端末間同期なし）

## キャッシュ方針

- Service Workerはproduction buildかつSecure Contextでだけ登録する。
- 開発サーバーでは登録せず、変更前のJavaScriptが残る事故を防ぐ。
- 本番ビルド時に配信ファイル一覧と内容ハッシュをService Workerへ埋め込む。スクリプト、CSS、全マップ、画像をインストール時にまとめてキャッシュする。
- ナビゲーションと事前キャッシュ対象は、そのWorkerがインストールしたバージョンを返す。配信更新中に旧HTMLと新JavaScriptを混在させない。
- 全ファイルの取得に失敗した新Workerはインストール完了しない。既存Workerは継続する。初回インストール失敗時はオンライン利用のみとなる。
- 事前保存対象外の同一オリジンGETはネットワーク優先で取得し、通信エラー/HTTPエラー時に取得済みキャッシュを利用する。
- APIリクエストはポートを含め別オリジンであり、Service Workerではキャッシュしない。
- キャッシュはアプリ配信物の復旧用であり、ゲーム進行の正式保存には使用しない。

初回アクセス前の完全オフライン起動は対象外。オンラインで初回インストールを完了してからオフライン再起動できる構成。2026-09-23のビルドは131ファイルを含み欠落0件を確認。画像だけで約44MBあり、空き容量と初回通信量の実機検証が必要。「一度ページが表示された」ことと「インストール完了」は同義ではない。

## 更新

新しいService Workerがインストール済み・待機中になった場合、「新しいバージョンを利用できます」と表示する。プレイヤーが「更新して再起動」を選ぶと、未保存の通常プレイでは先に保存完了を待つ。保存成功後に待機Workerへ切り替え、`controllerchange`後にページを再読み込みする。保存失敗時は再起動せず、端末保留と再試行を案内する。

## 実機QA

1. HTTPS環境のAndroid Chromeで「ホーム画面に追加」が表示される。
2. ホーム画面から起動するとブラウザUIなしの縦画面で表示される。
3. オンラインでWorkerのインストールを完了後、機内モードでアプリシェルと未訪問マップが開く。
4. オフライン中の保存が端末内で完了し、再起動で復元できる。サーバーへの再送は行わない。
5. 新バージョン配信後、更新通知から再起動できる。
6. 開発サーバーのApplication欄にMoribitoのService Workerが登録されない。

iOS Safariは独自のホーム画面追加UIを使用するため、自動インストールボタンではなく共有メニューから追加する。正式アイコン・スプラッシュ画像は正式アート工程でPNGを用意する。

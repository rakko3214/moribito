# ゲームエンジン選定

Status: Draft  
Last updated: 2026-07-28

## 背景

会話の前半ではGodot 4、後半ではUnity、ScriptableObject、Addressablesが記載されている。正式な技術決定は行われていない。

## 候補A：Godot 4

想定言語：GDScript

評価項目：

- 2D制作の扱いやすさ
- 無料・オープンソース
- 軽量なプロジェクト構成
- Codexによるテキストベース編集
- Android・iOS出力

確認事項：

- iOSビルド環境
- モバイルプラグイン
- 外部SDK
- 長期的な運用要件

## 候補B：Unity

想定言語：C#

評価項目：

- モバイル開発の事例とエコシステム
- 外部SDKとストア連携
- アセット・ツール
- ScriptableObject等によるデータ管理

確認事項：

- ライセンスと費用
- プロジェクトの複雑性
- 個人開発での保守負荷

## 決定手順

1. 課金方式・オンライン要件を決める。
2. 縦画面の仮想スティック、農業、料理ミニゲーム、ターン制戦闘を小規模に比較する。
3. Android実機で操作性とビルド手順を確認する。
4. iOS対応条件を確認する。
5. 採用理由をこの文書へ記録し、他候補を廃止する。

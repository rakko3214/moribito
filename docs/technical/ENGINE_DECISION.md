# ゲームエンジン選定

Status: Approved
Last updated: 2026-08-07

## 決定

MoribitoのFirst Playableは、Webブラウザ向け2Dゲームフレームワークの **Phaser** を使用して実装する。

基本技術スタック：

- 言語：TypeScript
- Web UI：React
- ビルド：Vite
- ゲーム本体：Phaser
- マップ制作：Tiled
- 描画：Phaser / WebGL
- 主要対象：スマートフォンブラウザ
- 対応対象：PCブラウザ

詳細は [`TECH_STACK.md`](TECH_STACK.md) を参照。

## 採用理由

- 2D見下ろし型のフィールド、農業、採取、リアルタイム戦闘に適している。
- スマートフォンとPCのWebブラウザを同一コードベースで対象にできる。
- スプライト、アニメーション、カメラ、入力、当たり判定、パーティクル、タイルマップを扱える。
- TypeScriptを中心に、Web UI、認証、クラウドセーブと接続しやすい。
- 既存のMoribito戦闘仕様を簡略化せず実装できる見込みがある。
- 個人開発でテキストベースの保守と自動化を行いやすい。

## 他候補の扱い

Godot、Unity、PixiJS、React単体はFirst Playableの基本技術には採用しない。

- Godot・Unity：ネイティブ展開や高度な3Dを中心にする場合は再検討できるが、Web中心のFirst Playableでは採用しない。
- PixiJS：描画基盤としては強力だが、ゲームシーン、入力、当たり判定などを自前で構成する範囲が増えるため採用しない。
- React単体：ゲーム本体には使用せず、Webアプリケーションの外側だけを担当させる。

将来、3D、高度なボーンアニメーション、大量の複雑な物理演算など、ゲームの前提自体が変わった場合に限り再評価する。

## 検証条件

First Playableではスマートフォン実機で次を確認する。

- 360度移動とタップ攻撃の操作性
- 村、森、農業、生活ミニゲームの描画と入力
- 弾、攻撃予兆、結界、浄化、ボス戦の性能
- 初回ロード、メモリ、発熱、フレームレート
- PCブラウザとの入力・レイアウト差

性能上の問題が出た場合は、ゲーム仕様を先に削るのではなく、オブジェクトプール、画面外更新の停止、アセット最適化、エフェクト品質設定などで対応する。

# 祖父の手帳

Status: Draft  
Last updated: 2026-07-28

## 目的

- 祖父の過去を伝える
- 神主とお告げへの伏線を置く
- プレイヤー自身に真相を推理させる
- 読まないプレイヤーには終盤の驚きを残す

## 基本仕様

- 主人公の家でいつでも読み返せる。
- メインクエストの完了などにより、新しいページが読めるようになる。
- 一部のページは破られており、後半で発見する案を採用候補とする。
- 神主を直接名指しする決定的記述は終盤まで避ける。

## 記述例

1. 「結師とは、村だけでなく真実を守る者でもある。」
2. 「お告げとは神の声そのものではない。伝える者がいる。」
3. 「人の言葉より、自ら聞いた声を信じなさい。」
4. 「神の声は結師にのみ届く。」
5. 「誰かの口からしか届かぬ言葉が、本当に神のものかを疑いなさい。」
6. 「あの者は神ではなく、自ら望む未来へ人々を導いている。」
7. 「もし私が姿を消したなら、この手帳がお前を真実へ導くだろう。」

# メインストーリー

Status: Draft  
Last updated: 2026-07-28

## 導入

村の守人だった祖父が行方不明になる。主人公は祖父の家へ移り住み、村人として生活しながら守人の役割を継ぐ。

神主は祖父と親しかった相談役として主人公を迎え、生活、神社、妖怪、守人の仕事を案内する。村長と村人は妖怪を災いの原因だと信じ、主人公へ討伐を求める。

## 前半

主人公は神主が伝えるお告げに従い、妖怪への対処を始める。農業、採取、修復、村人との交流が生活の中心となる。

お告げを受ける基本手順：

1. 章ごとの生活条件を満たす
2. 神社へ参拝する
3. 神主からお告げを受ける
4. メインクエストを遂行する
5. 神社へ報告する
6. 祖父の手帳の新しい部分が読める

## 中盤

主人公の行動によって妖怪のサブクエストが発生する。誤解を解いた妖怪と友情を築き、生活の協力を得る。

祖父の手帳には、お告げを伝える者、自ら聞く声、守人の本当の使命に関する記述が増える。神主は主人公が妖怪と友好関係を築くことに違和感を持つが、善人を装い、村長や別の人物へ疑いを向けさせようとする。

中盤の重要事件では、改ざんされたお告げによって、主人公が村を守る役割を持つ妖怪または封印へ手を出してしまう案がある。詳細は未決定。

## 後半

神主のお告げ改ざんと、祖父の失踪への関与が明らかになる。村長は利用されていたと知り、主人公側へ転じる。

対立を意図的に維持してきた勢力が村の外、国または組織へつながっていることが判明する。神主と国家組織の関係、祖父の生死、最終的な敵は未決定。

## 結末

守人の本当の使命が、人間と妖怪の双方を守り、均衡を維持することだと明らかになる。

村人の友情、妖怪との友情、穢れ、村の復興、サブクエストの達成状況に応じて未来の描写が変わる。理想的な結末では、村人と妖怪が神社前の祭りを共に楽しむ。

# 世界観

Status: Approved  
Last updated: 2026-07-28

## 舞台

巨大な御神木と神社を中心にした山間の和風の村。村の外には森、川、山、洞窟、湖、廃寺があり、外へ進むほど穢れと妖怪の影響が強くなる。

## 妖怪と人間

妖怪は昔から人間と同じ世界に存在する。しかし通常の人間には姿が見えない。村人は妖怪の存在を疑っておらず、代々の守人が妖怪を討伐できると認識している。

姿が見えないため、畑の被害、病気、事故などを妖怪の仕業だと判断する。未知への恐怖と、神主・村長から伝えられる情報によって、妖怪は一律に悪い存在だと思われている。

実際には、善良な妖怪、人間を警戒する中立妖怪、穢れに侵された妖怪、穢れから生まれた敵性存在がいる。

## 守人

守人は妖怪を視認し、結界を維持し、穢れを祓う役目を持つ。村では「妖怪を討伐して人間を守る者」と理解されているが、本来の使命は人間と妖怪の均衡を守ることにある。

## 穢れ

穢れは自然や生き物を蝕む力である。自然現象や災害に結び付く穢れと、恐怖・偏見・憎しみから生じる人の穢れがある。

## トーン

- 序盤：穏やか、温かい、少し閉鎖的
- 中盤：違和感、疑念、価値観の衝突
- 終盤：国や組織を含む陰謀、村と共存を守る緊迫感
- 結末：プレイヤーの行動により、人と妖怪が共に暮らす未来を目指す

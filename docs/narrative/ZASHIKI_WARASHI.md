# 座敷童子

Status: Partially Approved  
Last updated: 2026-08-04

## 役割

座敷童子は妖怪側の主要人物であり、昔の共存時代から村を見守ってきた歴史の証人である。主人公の幼少期の友人でもあり、祖父とも協力関係にあった。

## 幼少期

- 主人公は幼い頃、座敷童子やほかの妖怪と遊んでいた。
- 座敷童子にとって主人公は大切な友人だった。
- 祖父は主人公が次の結師に選ばれると察した。
- 神主が主人公の存在に気付き始めたため、祖父は主人公が狙われ、利用されると判断した。
- 祖父は座敷童子へ、主人公の妖怪に関する記憶を隠すよう頼んだ。
- 座敷童子は反対したが、主人公を守るため、自身の能力で記憶を封印した。

## ゲーム開始後

- プロローグから姿や気配が断片的に現れる。
- 主人公を陰から見守り、要所で助ける。
- 後半に入るまで主人公とは直接会話しない。
- 座敷童子が近づくほど記憶の封印が揺らぐため、会いたくても距離を取っている。
- 現神主に居場所を知られないよう姿を隠している。
- 主人公は座敷童子を知らないはずなのに、懐かしさを感じる。

## 記憶の回復

封印は完全な消去ではない。主人公が妖怪と縁を結び直すにつれて弱まり、夢、景色、匂い、音楽、祭りなどをきっかけに断片的な記憶が戻る。

終盤で封印が解け、主人公は座敷童子や妖怪たちと過ごした幼少期を思い出す。座敷童子が話しかけなかった理由と、長い間見守っていた事実も明らかになる。

## 視認条件

- 結師と神主は、基本的に妖怪を見ることができる。
- 子どもは一時的に座敷童子を見ることがあるが、常に見えるわけではない。
- 一般の大人には基本的に見えない。
- 現神主は座敷童子の存在を知っているが、居場所を特定できていない。

## 章配置の基準

- 第1～3章：姿、足音、助けられた痕跡のみ。
- 第4～6章：存在感と記憶の揺らぎを強めるが、直接会話はしない。
- 第7章以降：初めての直接会話候補。
- 第12章：記憶の封印を完全に解く候補。

章の厳密なタイミングはシナリオ制作時に調整するが、「後半まで直接会話しない」は確定とする。

## 友好度イベント

座敷童子は通常の加入フローを使用しない。記憶解放後に再び行動を共にし、友好度イベントでは失われた過去を繰り返し説明するのではなく、「これから思い出を作る」過程を描く。

| Rank | 内容 |
|---|---|
| ★1 | 昔と変わった村を一緒に歩く |
| ★2 | 主人公と協力して村人を助ける |
| ★3 | 村の子どもたちと遊ぶ |
| ★4 | 座敷童子が村への想いを語る |
| ★5 | 主人公と「これからも村を守ろう」と約束する |

## 妖怪札

- コンセプトは「主人公を幸運で守る守護妖怪」とする。
- 記憶解放後、再び行動を共にする段階でRank ★1を解放する。
- 直接攻撃は行わず、守護、幸運、生存補助に特化する。
- 1枚の妖怪札「守護・幸運」がRankに応じて発動効果を成長させる。複数の技を選択・装備する方式にはしない。

| Rank | 名称 | 効果 |
|---|---|---|
| ★1 | 福運 | 一定時間、主人公の移動速度を少し上昇させる |
| ★2 | 守り鈴 | 一定時間、最初に受ける攻撃を1回だけ無効化し、護身札も消費しない |
| ★3 | 福招き | 一定時間、素材ドロップ率とレア素材出現率を上昇させる |
| ★4 | 幸結界 | 効果時間中、護身札が0になった際に一度だけ護身札を1枚復活させる |
| ★5 | 家守りの祝福 | 一定時間、完全無敵状態になる |

「福招き」は効果時間中に倒した敵のドロップにのみ適用する。「守り鈴」の発動時は鈴の音と結界エフェクト、「幸結界」は幸運によって九死に一生を得る演出とする。「家守りの祝福」はボスの大技を凌ぐ、立て直す、攻撃機会を作るなど、発動タイミングをプレイヤーが判断する強力な防御効果とする。

戦闘中に座敷童子本体は同行しない。妖怪札の発動時のみ、座敷童子の幻影、鈴、結界の演出を短時間表示する。

# 主要キャラクター

Status: Draft  
Last updated: 2026-07-28

## 主人公

行方不明になった祖父の家と守人の役目を引き継ぐ。ゲーム開始時は村人と同様に妖怪を悪い存在だと考えているが、妖怪と直接話すことで価値観が変化する。

性別、名前、外見、発話形式は未決定。

## 祖父

先代の守人。村を守るだけでなく、人間と妖怪の均衡を保っていた。神主または背後の勢力が行う情報操作の真相へ近づき、行方不明になった。

主人公へ手帳を残している。現在の生死は未決定。

## 神主

### 表向き

- 神社の管理者
- 祖父と親しかった人物
- 主人公の相談役
- チュートリアルとナビゲーション担当
- 村で最も信頼される人物の一人

### 裏側

- 妖怪を見ることができる
- その事実を隠している
- お告げを改ざんして主人公を誘導する
- 妖怪との友好化を止めようとする
- 善人の姿を保ち、別の人物へ疑いを向けさせる

神主が最終黒幕か、国の組織に属する中間の敵かは未決定。

## 村長

村を守る責任感が強い。妖怪を見ることはできず、伝承と神主の言葉を信じて、妖怪討伐が村を守る方法だと考える。神主に利用されており、悪意はない。真相を知った後は主人公側となる。

## 親友

主人公と同年代で、村で最初に仲良くなる人物。明るく行動力があり、村の案内、季節イベント、探索、主人公の相談相手を担う。

序盤は妖怪を恐れ、主人公の友好化に反対することもある。主人公の行動を見て考えを変え、終盤では最初に主人公を支持する。

## 村人方針

- 約25人を想定
- 恋愛要素なし
- 全員に友情度を設定
- 会話、依頼、贈り物、祭り、個人イベントで友情を育てる
- 友情によって会話、協力、妖怪認識、物語上の反応が変化する

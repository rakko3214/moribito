# 穢れ・神気システム

Status: Partially Approved
Last updated: 2026-08-06

## 基本原則

- 妖怪と穢れは同一ではない。
- 恐怖、偏見、憎しみなどの負の感情に侵された妖怪が穢れ化する。
- 穢れ化した妖怪は理性を失い、人間、妖怪、自然環境へ害を与える。
- 初代神主は既に存在する穢れを集め、増幅し、操れるが、無から生み出せない。

## 自然の穢れ

穢れ化した妖怪などから村と自然へ広がり、日々のゲーム状態へ影響する土地側の汚染度。

増加要因：

- 時間経過
- 穢れ妖怪の放置
- 災害・異常気象
- ボスやストーリーイベント

減少要因：

- 不可逆穢れ妖怪の討伐
- 穢れ化妖怪の浄化
- 神社の修復
- 章ごとに指定された品の奉納
- 村人や妖怪の依頼
- 季節の祭り
- 結師の儀式

高い場合の影響：

- 作物の成長と品質低下
- 病気、枯れ、雑草の増加
- 採取量と希少素材率低下
- 川や湖の濁り
- 村人の体調と会話変化
- 善良な妖怪が姿を隠す
- 穢れ妖怪の増加
- 村の色、BGM、天候の変化

## 人の穢れ

恐怖、偏見、憎しみ、争いから生まれる物語上の力。妖怪を穢れ化させ、初代神主と神主一族が人間と妖怪の分断に利用する。

減少要因：

- 村人との友情
- 妖怪との和解
- 誤解を解くクエスト
- 妖怪が村を助ける出来事
- 村人が真実を知るイベント

人の穢れが薄れると、村人は妖怪を認識できるようになる。

## 神気

穢れを減らすだけでなく、土地へ良い力を育てるための要素。

上昇要因：

- 章の必須奉納
- 神社と御神木の修復
- 村人・妖怪との交流
- 祭り
- 土地の浄化

恩恵：

- 作物の成長、品質、収穫量向上
- 神気作物の発生
- 希少素材の出現
- 妖怪支援の強化
- お告げやイベントの解放

村全体ゲージと土地別ゲージの併用有無は未決定。

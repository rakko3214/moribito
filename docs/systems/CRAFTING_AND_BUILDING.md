# 制作・建築システム

Status: Placement Interaction Implemented
Last updated: 2026-08-24

## 役割分担

- 大工・樹：主人公宅の増築、倉庫、鶏小屋、家畜小屋、温室などの大型建築と家具レシピの販売を担当する。
- 作業台：家具、収納、柵、扉、家畜設備、屋外設備、装飾をプレイヤー自身が制作する。
- プレイヤー：素材を集め、レシピを入手し、制作物を屋内または主人公宅の敷地へ配置する。

## 作業台UI

- すべて、家具、柵・扉、家畜、装飾のカテゴリタブを表示する。
- 制作物名または素材名で検索できる。
- 現在の所持素材で制作可能なレシピだけに絞り込める。
- 必要素材、所持数、屋内・屋外の配置区分を一覧に表示する。
- 素材不足のレシピは選択できない。
- レシピの解放状態、制作物、素材消費はセーブ対象とする。

## First Playableの初期レシピ

- 木の椅子
- 家畜用の柵
- 柵の扉
- 木製看板

木の机、木の収納箱、餌箱、水飲み場は追加レシピとして定義し、大工や進行報酬から解放する。

### 樹工務店のレシピ販売

| レシピ | 価格 | 購入条件 |
|---|---:|---|
| 木の机 | 120文 | なし |
| 木の収納箱 | 180文 | なし |
| 餌箱 | 140文 | 鶏小屋または家畜小屋を依頼済み |
| 水飲み場 | 160文 | 鶏小屋または家畜小屋を依頼済み |

- レシピは一度だけ購入でき、購入時に作業台へ恒久的に追加する。
- 購入状態と所持金はセーブ対象とする。

## 配置仕様

- 制作後は持ち物へ入り、自宅または主人公宅敷地の配置メニューから設置する。
- マップ上をタップすると42pxグリッドへ吸着して配置候補を移動する。
- 配置前は半透明プレビューを表示し、設置可能なら緑、重複時は赤で示す。
- 屋内家具は自宅、屋外設備は主人公宅敷地だけへ配置できる。両対応品も定義できる。
- 主人公宅の室内は南側中央の出口だけを固定する。初期配置の寝床・作業台・収納を含む家具は回収し、配置可能範囲内の好きな場所へ再配置できる。
- 回転、決定、近くの配置物の直接移動、持ち物への回収・再配置に対応する。直接移動を中止した場合は元の位置へ残す。
- 柵は配置後に次のマスへ候補を移動し、所持数がなくなるまで連続配置できる。
- 耕作済みの土地、作物、未撤去の木・石、既存配置物との重複を禁止する。
- 主人公の現在位置へ重なる配置を禁止し、配置後の家具・建築・柵には移動当たり判定を持たせる。柵の扉だけは開状態で通行可能にする。
- 配置座標、向き、屋内・屋外マップをクラウドセーブへ保存する。

## 樹工務店と大型建築

- 村の樹工務店で、主人公宅の増築、鶏小屋、家畜小屋、温室を依頼できる。
- 依頼時に建築ごとのお金、木材、石材をまとめて支払う。素材不足の場合は依頼できない。
- 主人公宅は敷地内の固定位置にあり、大工への依頼で段階的に外観と機能を更新する。配置待ちの建築物にはしない。
- 主人公宅は「初期宅」「修繕・増築後」「最終増築後」の3段階を用意する。
- 第1段階の依頼には500文、木材20、石材10を使用する。第2段階の依頼は第1段階完了後に解放し、1200文、木材45、石材25を使用する。
- 鶏小屋、家畜小屋、温室は依頼後に配置待ちとして持ち物へ入り、主人公宅敷地でプレイヤーが建築場所を選ぶ。
- 大型建築も42pxグリッドへ吸着し、回転、配置可否プレビュー、他の建築・家具・柵・畑・木・石との重複防止に対応する。
- 依頼済みの同一建築は重複購入できない。自由配置する大型建築の座標と向きは通常の配置物と同じくセーブされる。

### 主人公宅の段階

| 段階 | 大工への依頼 | 外観・位置 | 想定する生活機能 |
|---|---|---|---|
| 初期宅 | 不要 | 古く小さな祖父の家。室内出口のみ固定 | 睡眠、基本収納、作業台、家具6個 |
| 第1段階 | 修繕・増築 | 屋根や壁を修繕し、一部屋と縁側を拡張 | 収納・家具配置範囲の拡張、家具12個 |
| 第2段階 | 最終増築 | 大きな母屋へ改築した完成形 | 最終住宅用の部屋・特別設備の受け皿、家具20個 |

現在のモックでは家具配置上限と室内の配置可能範囲を段階ごとに拡張する。特別設備の厳密な解放条件は別途確定する。
- First Playableの鶏小屋は250文、木材12、石材4とし、初期敷地の障害物撤去だけで最初の1棟へ到達できる。

## 配置物の利用

- 配置物へ近づくと、スマートフォンのアクションボタンがその配置物の操作へ切り替わる。
- 木の収納箱は自宅の共通倉庫を開く。
- 木の椅子は座って休む演出、木の机は調べる演出を表示する。
- 餌箱は餌を必要としている家畜へ所持餌をまとめて与える。
- 水飲み場は家畜と水の状態を確認する。
- 鶏小屋と家畜小屋は家畜管理画面を開く。
- 木製看板は30文字まで自由に文字を設定できる。
- 柵の扉は開閉でき、見た目の「開」「閉」が切り替わる。
- 看板の文字と柵扉の開閉状態は配置座標とともにセーブする。

鶏・家畜の日次飼育処理は `LIVESTOCK.md` の内容で実装済み。家具の詳細アニメーションや個別収納枠は製品UIフェーズで追加する。

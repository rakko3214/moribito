# 戦闘システム

Status: Draft  
Last updated: 2026-07-29

## 基本仕様

- フィールド上で敵へ接触すると専用画面へ移行する。
- ターン制コマンドRPG。
- 縦画面下部に大きなコマンドを配置する。

基本コマンド候補：

- 攻撃
- スキル
- 防御
- アイテム
- 逃げる

## 戦闘の位置付け

戦闘はレベル上げの主目的ではなく、生活圏の保護、穢れの浄化、素材や地域の解放、ストーリー進行に使用する。

## 敵の区別

### 穢れ化妖怪

元は善良または中立の妖怪。救済可能。戦闘の最終目的は浄化。

### 不可逆穢れ妖怪

既存の妖怪が穢れに完全に飲まれ、元の人格と状態を回復できなくなった存在。救済できず討伐対象となる。

### 通常妖怪

誤解や対立により戦う場合がある。必ずしも倒すことが正解ではなく、会話、撤退、クエストによる解決を検討する。

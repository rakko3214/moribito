# コアゲームループ

Status: Approved  
Last updated: 2026-08-06

## 日単位のループ

```text
朝の確認
  ├─ 畑の成長
  ├─ 天候
  └─ 妖怪の支援結果
       ↓
生活行動
  ├─ 農業
  ├─ 採取
  ├─ 料理
  ├─ 釣り・調合
  ├─ 修復
  └─ 村人・妖怪交流
       ↓
探索行動
  ├─ サブクエスト
  ├─ 素材探索
  ├─ 穢れ浄化
  └─ 戦闘
       ↓
帰宅
  ├─ 料理
  ├─ 手帳
  ├─ 倉庫
  └─ 就寝
```

## 物語ループ

```text
メインストーリー前半・中盤
  ↓
章ボス前イベント
  ↓
必須依頼・必須奉納を解放
  ↓
生活・交流・探索で条件達成
  ↓
神社で報告
  ↓
章ボス
  ↓
エンディングイベント・次章
```

## 設計原則

- 日数だけで物語を強制進行させない。
- プレイヤーは生活を続けるか、物語を進めるか選べる。
- 章ボス直前までは生活条件でメインストーリーを止めない。
- 必須依頼と必須奉納を章ボス解放条件として使用する。
- 奉納は反復報酬ではなく、章進行専用とする。
- 戦闘だけを繰り返して成長する構造にしない。

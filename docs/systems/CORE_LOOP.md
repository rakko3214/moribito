# コアゲームループ

Status: Approved  
Last updated: 2026-07-28

## 日単位のループ

```text
朝の確認
  ├─ 畑の成長
  ├─ 天候
  └─ 妖怪の支援結果
       ↓
生活行動
  ├─ 農業
  ├─ 採取
  ├─ 料理
  ├─ 修復
  └─ 村人・妖怪交流
       ↓
探索行動
  ├─ サブクエスト
  ├─ 素材探索
  ├─ 穢れ浄化
  └─ 戦闘
       ↓
帰宅
  ├─ 料理
  ├─ 手帳
  ├─ 倉庫
  └─ 就寝
```

## 物語ループ

```text
生活・交流・修復で条件達成
  ↓
神社へ参拝
  ↓
お告げを受ける
  ↓
メインクエスト発生
  ↓
探索・対話・戦闘
  ↓
神社へ戻る
  ↓
物語・手帳・新機能解放
```

## 設計原則

- 日数だけで物語を強制進行させない。
- プレイヤーは生活を続けるか、物語を進めるか選べる。
- 農業、料理、友情、修復をメイン進行条件に使用する。
- 戦闘だけを繰り返して成長する構造にしない。

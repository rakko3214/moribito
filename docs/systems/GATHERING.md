# 採取システム

Status: Draft  
Last updated: 2026-07-28

## コンセプト

四季と自然を感じ、農業では得られない料理・修復素材を集める。金策だけを目的にしない。

## エリア

- 森：木材、果実、きのこ、薬草、花、妖怪の落とし物
- 山：山菜、木の実、鉱石、希少植物
- 川：水草、わさび、河原の石、魚
- 湖：魚、水生植物、夜限定素材
- 洞窟：鉱石、石材、穢れ素材
- 神域：神木、神花、神薬草、神鉱石など

## 季節例

- 春：よもぎ、たけのこ、ふき、山菜
- 夏：梅、山桃、清流魚
- 秋：栗、松茸、銀杏
- 冬：ゆず、寒魚、山芋

## 操作候補

- 草花：接近してアクション
- 木の実：スワイプ
- 木材：短いリズムタップ
- 鉱石：タイミング採掘
- 珍しい素材：5～10秒程度のミニゲーム

通常素材を毎回ミニゲームにすると反復負荷が高いため、簡易採取と丁寧採取を分ける案を検討する。

## 穢れ・神気

穢れが高い場所では素材量・品質・希少率が低下し、穢れ素材が出現する。神気が高い場所では高品質・希少素材と妖怪イベントが増える。

## 妖怪支援例

- 木霊：森の採取量
- 河童：川の採取
- 天狗：山の希少素材
- 妖狐：珍しい素材の場所を知らせる

# 料理システム

Status: Approved  
Last updated: 2026-09-14

## コンセプト

ASMR、癒やし、シンプルなスマホ操作を組み合わせ、料理を作る工程自体を楽しむ。スピード競争ではなく、心地よさと軽い達成感を重視する。

## 基本フロー

1. レシピを選ぶ
2. 材料を確認する
3. 2～4工程のミニゲームを遊ぶ
4. 工程評価から料理品質を決める
5. 使用目的を選ぶ

## 案内役と店舗

食事処「なごみ亭」の店主・楓が料理チュートリアルを担当する。包丁、火加減、味付け、盛り付け、品質、料理効果、料理の奉納を順に教え、最初の料理を完成すると料理システムを解放する。

なごみ亭では食事、持ち帰り料理、レシピ、季節限定料理を扱い、料理の納品依頼も受け付ける。営業終了後は、人には見えない妖怪たちも料理を囲む共存の象徴的なイベント場所となる。

料理は画面固定ボタンや設備上の大きなアイコンからではなく、なごみ亭の調理台前へ近づいて「調理台を使う」を実行して開始する。かまど、棚、調理台、椅子には外観に沿った当たり判定を設け、主人公が設備へ重ならないようにする。

## 操作例

- 切る：線に沿ってスライド、リズムよくスワイプ
- 混ぜる：左右交互に短くスワイプする
- 焼く：適切なタイミングでタップして裏返す
- 味付け：ゲージの範囲で止める
- 盛り付け：木椀の中央を順にタップする

操作は片手で行える規模とし、1工程を短くする。

火加減工程では、画面上部に楓の助言と残り時間、中央に鍋と火力計、下部に仕上がりゲージを表示する。画面を上下へ滑らせて火力マーカーを適温帯へ合わせる。炎の大きさと煮汁の色も現在の火力・焦げ状態に連動し、文字だけに頼らず状況を判断できるようにする。

ご飯料理では、木椀、米粒、よもぎ、しゃもじを画面へ表示する。工程1は左右交互のスワイプ6回を丸い進捗表示へ反映し、工程2は木椀中央への3回のタップを盛り付けとして視覚化する。工程切替、成功操作、完成時には調理・環境音と端末振動のフィードバックを返す。

## 評価

- Perfect
- Great
- Good
- Miss

完成品質：

- 普通
- 良質
- 上質
- 極上

完成後は専用の結果画面を表示し、完成料理のアイコン、品質、獲得数、使用効果を確認できる。「続けて料理する」から献立帳へ戻ることもできる。

Missがあっても原則として料理は完成する。高級料理ほど操作を難しくするのではなく、工程数を増やす。

## ASMR

- 包丁の音
- 野菜を切る音
- 混ぜる音
- 煮える音
- 焼ける音
- 盛り付け音

音量設定でASMR、BGM、通常効果音を個別調整できる設計を検討する。

## 繰り返し対策

- 初回：すべての工程を遊ぶ。
- 2回目以降：ミニゲームまたはおまかせ調理を選択できる。
- おまかせ調理：手作りで一度成功した料理ごとに解放する。材料を通常どおり消費し、普通品質を1個完成させる。
- 献立帳には料理ごとの習得状態と、全8品中の習得数を表示する。

## 用途

- 戦闘中の護身札回復
- 霊力・生活スタミナ回復
- 一時的な能力強化
- 村人への贈り物
- 妖怪へ振る舞う
- クエスト
- 章の必須奉納

料理は奉納カテゴリの一つとする。章によって、料理以外の農作物、魚、採取素材、調合品、浄化素材も奉納対象になる。

## 戦闘への持ち込み

- 料理は戦闘中に使用できる。
- 戦闘中に料理メニューを開いている間は戦闘を停止する。
- First Playable収録の完成料理8種は、いずれも護身札を1枚回復する。
- 上位効果へ拡張する場合は、料理ごとの回復量と追加効果を個別設定する。
- 戦闘へ持ち込める料理には個数上限を設ける。
- 上位料理には霊力回復、状態異常解除、一時強化などを追加できる。
- 最大枚数を超えた護身札回復は発生させない。

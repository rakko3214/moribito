# 調合システム

Status: First Playable Implemented
Last updated: 2026-08-15

## 役割

採取した薬草や素材から、戦闘と生活を補助する消耗品を作る。第2章までに基本機能を解放し、ゲーム全体の生活サイクルへ組み込む。

## 用途

- 回復薬
- 状態異常回復薬
- 穢れ耐性薬
- 一時的な能力上昇薬
- 章の必須奉納に指定される調合品

## 第2章

- 基本的な調合操作を解放する。
- 初級素材と初級レシピだけを扱う。
- 第2章の必須奉納で使用する場合は、チュートリアルで作れる難度と数量にする。

## First Playable確定仕様

- 診療所で宗玄から調合を学ぶ。
- 円を描く速さと方向を、青・遅、赤・速、黄・維持、紫・逆の指示へ合わせる。
- 回復薬は通常難易度、清め薬は指示時間が長い上位難易度とする。
- 品質は大成功、成功、不完全、失敗で評価する。
- 大成功では完成数が2個になる。
- 失敗時も素材を消費し、全レシピ共通で粗悪品が完成する。

### First Playable仮レシピ

| 調合品 | 材料 | 難易度 | 仮用途 |
|---|---|---|---|
| 回復薬 | よもぎ | 通常 | 基本回復 |
| 清め薬 | よもぎ2 | 上級 | 清め・奉納 |
| 解毒薬 | よもぎ、きゅうり | 通常 | 状態異常回復 |
| 穢れ除け薬 | よもぎ2、浄化の欠片 | 上級 | 穢れ耐性 |
| 霊力薬 | よもぎ、人参 | 熟練 | 霊力回復 |

通常は10秒、上級は12秒、熟練は14秒の指示に対応する。用途の効果量、所持上限、レシピ入手条件は製品化工程で確定する。

レシピの入手経路、薬の所持上限、料理との回復役割の最終分担は製品化工程で調整する。

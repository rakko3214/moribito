# 調合システム

Status: Partially Approved
Last updated: 2026-08-06

## 役割

採取した薬草や素材から、戦闘と生活を補助する消耗品を作る。第2章までに基本機能を解放し、ゲーム全体の生活サイクルへ組み込む。

## 用途

- 回復薬
- 状態異常回復薬
- 穢れ耐性薬
- 一時的な能力上昇薬
- 章の必須奉納に指定される調合品

## 第2章

- 基本的な調合操作を解放する。
- 初級素材と初級レシピだけを扱う。
- 第2章の必須奉納で使用する場合は、チュートリアルで作れる難度と数量にする。

## 未決定

- 調合操作とミニゲームの有無
- 調合設備
- レシピ入手方法
- 品質、失敗、素材代替のルール
- 調合担当として挙がっている蓮と薬師・宗玄の役割分担
- 料理、薬、護身札回復の役割分担

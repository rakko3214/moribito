# 釣りシステム

Status: Partially Approved
Last updated: 2026-08-05

## 役割

- 生活要素、料理素材、収集要素の入手手段とする。
- 川、湖、季節、時間、天候によって釣れる魚を変える。
- 漁師・源三を案内役とし、川の異変から河童の物語へつなげる。
- スマートフォンでも短時間で遊べる操作を目指す。

## 案内役

源三が次の要素を段階的に教える。

- 釣り竿の使い方
- 魚影
- レア魚
- 天候と時間帯
- 魚の品質

漁具小屋では、釣り竿、ルアー、餌、魚籠、釣り図鑑を扱う。

## 物語との連携

中盤、源三が魚の減少や川の荒れを主人公へ相談する。この異変を調べる流れから、河童や穢れに関わる物語へ入る。

源三は妖怪を見ることができないが、「川には人には見えない何かがいる」という言い伝えを知り、川を大切にしている。河童に関わる出来事の後も、直接見えない存在を受け入れる立場になる。

## 今後決める内容

- 基本操作と1回の所要時間
- 難易度
- 釣り竿、ルアー、餌、魚籠の性能差と強化
- 魚の品質とレア魚
- 穢れた魚
- 祭りの釣り大会
- 妖怪による支援

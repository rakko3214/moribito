# 時間・季節・スタミナ

Status: Draft  
Last updated: 2026-07-28

## 時間

採用候補：

- 1日：6:00～24:00
- 5秒でゲーム内10分
- 1日あたり実時間約9分

9分は短い可能性があるため正式決定ではない。12～18分の案と実機比較する。

## 時間停止候補

- 会話中
- 戦闘中
- メニュー中
- 料理ミニゲーム中
- イベント・カットシーン中
- 神社でのお告げ中

## 季節

- 春
- 夏
- 秋
- 冬
- 各季節30日案

季節により作物、魚、採取物、妖怪、祭り、天候が変化する。

## 天候

- 晴れ
- 曇り
- 雨
- 台風
- 雪
- 霧・異常気象

雨は水やり不要。台風や異常気象は修復や穢れに関係する。

## スタミナ

農作業、伐採、採掘、釣りなどで消費する。通常移動では消費しない。ダッシュの消費有無は未決定。

回復方法：

- 食事
- 就寝
- 温泉
- 妖怪の支援

スタミナ切れの罰則と夜更かしの扱いは未決定。

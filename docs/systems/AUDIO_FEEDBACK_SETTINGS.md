# 音響・振動・演出設定

Status: Foundation Implemented

設定はアカウントの進行データではなく端末ごとの操作環境としてローカル保存する。ポーズメニューからいつでも変更できる。

- BGM音量：0～100%
- 効果音音量：0～100%
- 調理・環境音音量：0～100%
- 振動：ON/OFF
- 演出軽減：ON/OFF
- 移動感度：80～120%
- 画面揺れ：ON/OFF
- 軽量演出：ON/OFF
- 文字拡大：ON/OFF
- 高コントラスト：ON/OFF
- 戦闘文字予兆：ON/OFF

正式音源の導入前はWeb Audioによる仮音源で、音量と再生タイミングを実機確認する。ゲーム再開中は小さな環境音を周期再生し、ポーズ・タイトル・ログアウト時は停止する。成功、失敗、被弾は異なる短音にし、料理・調合・鍛冶・釣り・収穫は調理環境音チャンネルへ分ける。正式BGM・効果音へ差し替える際も、3系統の音量、画面遷移、ゲーム通知契約は維持する。

振動は生活行動の成功・失敗と戦闘被弾へ接続する。振動APIに対応しない端末では何も行わず、ゲーム進行へ影響させない。演出軽減時はWeb UIのアニメーションとトランジションを最小化する。移動感度、画面揺れ、軽量演出はゲーム本体へ即時反映し、軽量演出では雨の描画密度と無限反復表示を抑える。

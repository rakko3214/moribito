# 神社・お告げ・奉納

Status: Partially Approved
Last updated: 2026-08-06

## 神社の役割

- メインストーリー進行と章ボス前の報告
- お告げ
- 必須奉納の受付と進捗確認
- 穢れの浄化、神気、結界に関する物語
- 季節祭と神社修復

## 章の進行

メインストーリーは章ボス直前まで通常どおり進められる。章ボス前イベントで、その章の必須依頼と必須奉納を解放する。

両方を達成すると「神主へ報告しましょう」と表示し、神社での報告イベント後に章ボスへ挑戦できる。

## 奉納の役割

奉納は村人依頼と並ぶメインストーリー進行専用システムとする。自由な追加奉納、奉納値、反復報酬などのやり込み要素は実装しない。

- 村人依頼：村や住民の問題を解決する。
- 奉納：生活で得た品を祭事や神事のために納める。

## 奉納方法

- 神社の祭壇から行う。
- 集めた分から途中奉納できる。
- 奉納したアイテムはその場で所持品から消費する。
- 必要数へ達したカテゴリは受付を停止し、過剰投入を防ぐ。
- クエスト専用品、装備品、一点物、祖父の遺品、預かり品、重要素材は奉納できない。

## 奉納品

基本は特定アイテムではなくカテゴリと必要数を指定する。

- 野菜・農作物
- 魚
- 採取素材
- 料理
- 調合品
- 浄化素材

ストーリー上必要な場合だけ特定アイテムを指定する。章ごとに3～4分野程度を選び、その章までに解放済みのシステムだけを要求する。

序盤は品質条件を設けず、通常品質でも高品質でも1個として数える。

## UI

祭壇で必須依頼と必須奉納の進捗をまとめて確認できる。

```text
【依頼】
✓ 畑
□ 森
✓ 川

【奉納】
野菜　　　3/5
料理　　　2/2
魚　　　　1/3
浄化素材　5/5
```

## 第2章

奉納は章ボス前イベントで解放する。農業、採取、料理、釣り、調合、戦闘のうち、解放済みの3～4分野を少量ずつ体験すれば達成できる内容にする。高品質品や希少品は要求しない。

## お告げと物語上の意味

前半は神主がお告げを解釈して伝え、その内容を改ざんする。神主は奉納を村の大結界を維持するためと説明する。

奉納によって結界が穢れの流れを捉え、章ボスの場所が判明する。ただし後半では、奉納で生じた力の一部を神主側が利用し、本来の意味を歪めていた可能性を明かす。

真のお告げを主人公が聞く時期と方法、奉納の本来の意味は未決定とする。

# 神社・お告げ・奉納

Status: Draft  
Last updated: 2026-07-28

## 神社の役割

- メインストーリー進行
- お告げ
- 料理の奉納
- 穢れの浄化
- 神気の回復
- 妖怪との儀式
- 季節祭
- 神社修復

## 章の進行

章ごとに生活条件を設定する。

条件例：

- 必要素材
- 村人友情
- 妖怪との和解
- 神社修復
- 特定の料理
- 村の穢れ・神気
- 特定サブクエスト

条件達成後に神社へ参拝し、お告げを受けることでメインクエストが始まる。完了後に神社へ戻ると物語が進む。

## お告げ

神は答えを直接説明せず、行き先や目的を示す短い言葉を伝える。

例：

- 「西の森に悲しき声あり。」
- 「枯れゆく川を救え。」
- 「月が満ちる夜、古き社へ向かえ。」

前半は神主が解釈して伝え、その内容を改ざんする。主人公が真のお告げを聞く時期と方法は未決定。

## 奉納

- 生の作物は奉納できない。
- 収穫物や採取物を料理し、完成した料理を奉納する。
- 品質と料理の種類により神気・浄化効果が変わる。
- 特定料理を章や祭りの条件に使用できる。

## 修復候補

- 本殿
- 鳥居
- 灯籠
- 御神木周辺
- 社務所
- お守り工房

# 村人依頼

Status: First Playable Implemented

## 方針

村人本人へ必要な品を持って話しかけると納品する。依頼はQuestとして保存し、同じ依頼を重複開始・重複完了しない。ひとりの村人が複数依頼を持つ場合は、所持品で達成可能な依頼を優先して納品する。

# 生活UI

Status: First Playable Mobile UI Implemented
Last updated: 2026-08-24

## 共通生活メニュー

- 料理、調合、釣り、鍛冶、作業台、建築、家畜、持ち物、倉庫は同じパネル構造を使用する。
- 画面高620px未満では1ページ3項目、それ以上では1ページ4項目を表示する。
- 項目数が表示上限を超える場合は「前へ」「次へ」を表示し、ページ単位で切り替える。
- 選択できない項目は暗色にし、素材不足、所持金不足、依頼済みなどの理由を詳細欄へ表示する。
- 閉じる操作は常にメニュー末尾へ表示する。進行中のミニゲームは誤操作防止のため二度押しで中断する。

## 持ち物

- 「すべて」「素材」「食べ物」「薬・結晶石」「家具・建築」のカテゴリを用意する。
- 選択中カテゴリ、所持金、かばん内容、倉庫内容を同じ画面で確認できる。
- 未知のアイテムIDも欠落させず、そのまま表示する。

## スマートフォン方針

- パネル幅は画面左右に12px以上の余白を確保する。
- 短い画面ではボタン間隔と1ページの項目数を減らし、画面外へ操作項目が出ないようにする。
- 操作対象へ近づいた際は右下のアクションボタンを対象ごとの文言へ切り替える。
- 本フェーズはFirst Playable用の機能UIであり、最終画像素材、アイコン、アニメーション、アクセシビリティ調整は製品UIフェーズで行う。

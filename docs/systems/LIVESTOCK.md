# 家畜システム

Status: First Playable Implemented
Last updated: 2026-08-22

## 基本導線

1. 樹工務店へ鶏小屋または家畜小屋を依頼する。
2. 主人公宅敷地で小屋の場所を選んで建築する。
3. 敷地の家畜管理から鶏または牛を迎える。
4. 餌を購入し、毎日家畜へ与える。
5. 成長後に発生する卵または牛乳を回収する。

## 飼育条件

- 鶏は配置済みの鶏小屋が必要で、4羽まで飼育できる。
- 牛は配置済みの家畜小屋が必要で、3頭まで飼育できる。
- 鶏は100文、牛は500文で迎える。
- 家畜の餌は5個75文で購入する。
- 餌やりは1匹につき1日1個。まとめて餌を与える操作にも対応する。

## 成長と生産

- 餌を与えて就寝すると年齢が1日進み、友情が5上昇する。
- 餌を与えなかった日は成長と友情上昇が停止する。罰則や死亡は設けない。
- 鶏は3日、牛は5日で成体となる。
- 成体へ餌を与えた翌朝、鶏は卵、牛は牛乳を生産する。
- 未回収の生産物は消失せず、まとめて回収できる。

## セーブ

家畜ID、種類、名前、年齢、友情、当日の給餌状態、生産物の回収待ち状態をクラウドセーブへ保存する。旧セーブに家畜データがない場合は空の飼育状態から開始する。

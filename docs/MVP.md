# 最初の垂直スライス

Status: Draft  
Last updated: 2026-07-28

## 目的

農業、料理、妖怪交流、神社クエスト、戦闘が一つのゲームとして楽しいかを、少ないコンテンツで検証する。

## 推奨範囲

- ゲーム内7日間
- 村、主人公宅、畑、神社、森
- 村人5人
  - 神主
  - 村長
  - 親友
  - 商店主
  - 農業の先生
- 妖怪3体
  - 木霊
  - 河童
  - もう1体
- 穢れ化妖怪1体
- 固有穢れ妖怪1体
- 作物4種類
- 料理3種類
- 採取素材6～8種類
- 農業、収穫、料理、奉納の基本ループ
- ターン制戦闘1セット
- メインクエスト1本
- 妖怪サブクエスト1本
- 祖父の手帳2ページ
- ローカルセーブ

## 完了条件

- 縦画面の仮想スティックで不便なく移動できる。
- 1日単位の生活に過度な時間的圧迫がない。
- 農業から料理、奉納へつながる動機が分かる。
- 妖怪を浄化する戦闘と討伐する戦闘の違いが伝わる。
- 神主を自然に信用できる。
- 妖怪への認識が変わる最初の体験が成立する。

## コンセプト

御神木を中心に栄えた山間の小さな和風の村。プレイヤーが毎日帰りたくなる故郷を目指す。村は比較的安全で、外へ出るほど穢れと危険が増える。

## 全体構成

```text
                 神社
                  │
              巨大御神木
                  │
      商店 ── 広場 ── 茶屋
        │       │       │
     診療所   掲示板   鍛冶屋

       村長宅         神主宅
          村人の家々

             主人公の家
             畑・倉庫

        川・橋・農地の外周

      森 ← 村の外 → 山
          洞窟・湖
             廃寺
```

## 施設

- 神社：お告げ、奉納、浄化、物語
- 御神木：村の象徴、物語の核心
- 広場：祭り、朝市、村人交流
- 商店：種、食料、日用品
- 茶屋：料理、休憩、交流
- 鉄火堂：神具・妖怪札の強化、鉱石の精錬、素材加工、採掘道具
- 診療所：回復、薬、穢れ研究
- 漁具小屋：釣り竿、ルアー、餌、魚籠、釣り図鑑
- 樹工務店：家・倉庫・家具・橋・階段・村施設の建築と修復
- 主人公宅：睡眠、料理、手帳、倉庫、クラフト、改築
- 畑：農業と妖怪支援

## 外部エリア

- 森：最初の探索地、木霊、木材、薬草
- 川：釣り、河童、水路
- 山：採掘、天狗、希少素材
- 洞窟：中盤以降、穢れ妖怪
- 湖：夜・水妖怪・幻想的イベント
- 廃寺：祖父の足跡、終盤の真相

## 発展

依頼、修復、友情、ストーリーにより以下が変化する。

- 花や装飾が増える
- 店の商品が増える
- 建物が修復される
- 村人が外で活動する
- 妖怪の姿や気配が加わる
- 神社が回復する
- 祭りが開催される
- BGM、色、会話が明るくなる

村の発展は、人間と妖怪の共存度とも連携する。共存度が上がると、妖怪が村を訪れ、村人が妖怪を認識し、共同の仕事や祭りが発生する。

## 目的

プロローグから第3章終了までに必要な場所を、正式なTiledマップへ移すための制作単位、接続関係、配置責務、進行制御を定義する。

本書では敵の正確な座標や同時出現数を確定しない。先に通路幅、障害物、カメラ範囲、生活導線、イベント空間を完成させ、その後に敵配置と戦闘バランスを調整する。

## 設計原則

- 村は安全な生活拠点とし、村外れから先で危険度を上げる。
- 主人公宅、畑、倉庫をまとめた屋外敷地は村中央へ直接置かず、村南側へ接続する生活拠点として分ける。
- 通常戦、化け蛙戦、淀みの大樹戦を同じ場所へ重ねない。
- 第1章の初戦闘は「神社からの帰り道にある村外れまたは森の入口」で発生させる。
- 生活施設は村中央から短時間で往復できるようにし、毎日の移動を負担にしない。
- 森は入口、探索域、ボス域へ段階的に危険度を上げる。
- ボスエリアの入口には準備確認と引き返せる安全地点を設ける。
- 重要な操作対象や攻撃予兆を、スマートフォン縦画面の表示範囲外へ偏らせない。
- マップ固有の地点、イベント、採取、NPC、敵候補はTiled Object Layerへ置き、Sceneへの座標直書きを減らす。

## 全体接続図

```text
                         神社
                          │
                    神社参道・村外れ
                 （第1章の初戦闘地点）
                          │
 川・釣り場 ─────── 村中央 ─────── 森入口
     │                │  │  │              │
 漁具小屋          商店  │  鉄火堂       森探索域
     │              なごみ亭              │
   古池          診療所・村長宅       淀みの大樹
 （化け蛙）             │
                         │
                 主人公宅の屋外敷地
                    │          │
                 主人公宅     畑・倉庫
```

移動関係は双方向を基本とする。物語で未解放の道は見えない壁ではなく、倒木、濁流、作業中、村人の制止など世界内の理由で閉じる。

## マップ別配置要件

### `map_homestead`

- 初回操作開始地点は祖父宅の玄関付近とする。
- 家、畑、倉庫、水場を一画面ですべて操作できるほど密集させず、数秒で往復できる距離に置く。
- 村へ向かう北側の道へ、しきが自然に誘導できる視線と通路を作る。
- 農業チュートリアル用区画と、後から拡張する区画を視覚的に分ける。
- 村中心の建物群とは別マップにし、「村の中に主人公宅が埋め込まれている」見え方を避ける。

### `map_village`

- 中央に広場、掲示板、御神木への視線軸を置く。
- 商店、なごみ亭、鉄火堂、診療所、村長宅へ広場から短時間で到達できる。
- 神社は北、主人公宅の敷地は南、川は西、森は東という基本方向を維持する。
- NPCの日課移動に使える周回路と、イベント時に複数人を並べられる空間を確保する。
- 通常敵は配置しない。物語イベント以外では安全な場所とする。

### `map_shrine_approach`

- 村と神社の間に置き、第1章の「無人の神社から帰る途中」の初遭遇を成立させる。
- 初戦闘前は通り道、初戦闘時はチュートリアル戦闘域として使用する。
- 戦闘域は逃げ道を完全に塞がず、村長と神主の登場イベントで自然に戦闘範囲を示す。
- 初戦闘後は安全化し、通常の往復路へ戻す。

### `map_shrine`

- 鳥居、参道、本殿、祭壇、社務所、御神木周辺を識別できる構成にする。
- 祭壇で必須依頼・奉納の進捗をまとめて確認する。
- 結界チュートリアル用の空間を確保するが、通常敵や化け蛙は常設しない。
- 神主との報告イベントと、章ボス解放イベントの立ち位置を分ける。

### `map_river`

- 複数の釣り可能地点、川辺採取、水路の流れを配置する。
- 安全な生活区域を基本とし、穢れ発生時だけ一部の水辺を危険化できる。
- 古池へ続く上流または支流を視覚的に示す。
- 第2章前後で水色、魚影、採取物、NPC行動を差し替えられるようにする。

### `map_old_pond`

- 平常、穢れ増加、浄化後の3状態を同じ地形上で表現できる。
- ボス入口の手前に準備確認、安全地点、引き返す導線を置く。
- 戦闘域は濁流、穢れ沼、回転弾の予兆が縦画面でも読める広さを確保する。
- 第3章冒頭に再訪し、浄化後の化け蛙と回復した環境を確認できる。

### `map_forest_edge`

- 村から最初に訪れる採取地域とし、木材、薬草、きのこ等の採取候補を置く。
- 第1章では一部だけ、第3章では森探索域への道を解放する。
- 通常穢れとの遭遇候補地を作るが、敵座標は地形完成後に決める。
- 一本道にせず、小さな迂回と見通しの良い帰路を用意する。

### `map_forest_depths`

- 陽太の落とし物、足跡、折れた枝、木の実、不自然な植物を順序を変えても追えるように配置する。
- 危険な崩落路と、木霊が示した安全な迂回路を視覚的に対比する。
- 木霊が陽太を守る初遭遇には、主人公が状況全体を一度に認識できる演出空間を置く。
- 通常穢れと探索対象が同時に画面へ密集しないよう、戦闘区画と調査区画を緩やかに分ける。

### `map_yodomi_grove`

- 大樹、本体攻撃位置、根の包囲、安全地帯候補3か所以上を確保する。
- 木霊と陽太は戦闘エリア端の安全な演出位置へ置き、戦闘対象にしない。
- 地形の装飾と攻撃予兆の色・形が競合しないようにする。
- 戦闘前、戦闘中、浄化後の環境レイヤーを切り替えられる構造にする。
- 浄化後に木霊を見送るためのカメラ移動と退場経路を確保する。

## Tiledレイヤー規約

各マップは必要に応じて次のレイヤーを持つ。

| レイヤー | 用途 |
|---|---|
| `Ground` | 地面タイル |
| `GroundDetail` | 草、道の縁、水面等 |
| `Buildings` | 建物、橋、大型地形 |
| `AbovePlayer` | 木の梢、屋根等の前景 |
| `Collisions` | 壁、水、崖、通行不可領域 |
| `Transitions` | 接続先Map IDとSpawn ID |
| `Spawns` | 開始、各入口、イベント復帰地点 |
| `Interactables` | 扉、祭壇、設備、調査対象 |
| `NpcSpawns` | NPC ID、時間帯、進行条件 |
| `EventZones` | 会話、カットシーン、章進行 |
| `GatheringNodes` | 採取物ID、再出現規則 |
| `FishingSpots` | 水域ID、魚テーブル |
| `EnemySpawnCandidates` | 敵配置候補。正式配置は地形確定後 |
| `CameraZones` | ボス、イベント、狭所の表示制御 |
| `AudioZones` | BGM、環境音、穢れ状態 |

Objectには用途に応じて安定した `id`、`condition`、`stateVariant`、`targetMap`、`targetSpawn` 等を設定する。章進行条件をマップ名や座標だけで判定しない。

## 敵配置を開始できる条件

次を満たしたマップだけ、正式な敵配置へ進む。

1. プレイヤーの移動可能範囲と衝突が確定している。
2. スマートフォン縦画面で通路と回避空間を確認済みである。
3. 採取、調査、NPC、イベント地点が確定している。
4. 戦闘開始・見失い・終了後の帰路を確保している。
5. 攻撃予兆と背景装飾の視認性を確認している。
6. ボス戦では準備確認、敗北復帰、再挑戦地点が決まっている。

地形確定前は、近接、遠距離、突進、範囲、特殊の役割と候補区画だけを定義する。正確な座標、同時数、索敵距離、再出現周期は試遊で決定する。

## 現行モックとの差分

| 現行 | 正式マップでの変更 |
|---|---|
| `map_village`に主人公宅外観、畑、採取、料理、釣り、調合、店を集約 | 主人公宅の屋外敷地、村中央、各施設、川へ分離 |
| `map_shrine`に通常戦と化け蛙を仮配置 | 初戦闘を神社参道へ、化け蛙を古池へ移動 |
| `map_forest`に痕跡、木霊、淀みの大樹を集約 | 森入口、森探索域、淀みの大樹へ分離 |
| 生活設備と採取座標を`WorldScene`へ直書き | Tiled Object Layerまたは検証済みJSONへ移行 |
| 敵は操作用マーカーから開始 | 地形確定後に索敵する敵Entityへ置換 |
| 章進行前でも各ボスへ接近可能 | 依頼、奉納、報告、探索条件によるゲートを実装 |
| 環境は基本的に一状態 | 古池と森に穢れ前・穢れ中・浄化後の差分を実装 |

## 制作順

1. 共通タイル、当たり判定、Transition、Spawnの規約を確定する。
2. `map_homestead`、`map_home`を制作し、開始・睡眠・農業を移す。
3. `map_village`と優先度Bの施設を制作し、第1章生活導線を通す。
4. `map_shrine_approach`、`map_shrine`を制作し、第1章初戦闘を移す。
5. `map_river`、`map_old_pond`を制作し、第2章を通す。
6. `map_forest_edge`、`map_forest_depths`を制作し、第3章探索を通す。
7. `map_yodomi_grove`を制作し、第3章ボスと別れを通す。
8. 全マップをスマートフォン縦画面で確認する。
9. 通常敵の正式配置、索敵、戦闘解除、リスポーンを調整する。
10. NPC日課、採取、釣り、環境差分、音響を最終調整する。

## 実装進捗

### 2026-08-25：正式マップデータ基盤フェーズ

- 全16マップを一元管理するマップマニフェストと、移行優先順位を追加した。
- Tiled JSONのサイズ、32pxタイル、必須プロパティ、Object Layer、ID重複、範囲外配置を自動検査するようにした。
- 全Transitionの接続先Map・Spawnと、Spawnが衝突領域内にないことをマップ集合単位で検査するようにした。
- `Interactables`、`NpcSpawns`、`EventZones`、`GatheringNodes`、`FishingSpots`、`EnemySpawnCandidates`、`CameraZones`、`AudioZones`をローダーで共通解析できるようにした。
- `map_homestead`の採取物、家畜設備、農業イベント領域、48区画の農地レイアウトをObject Layerへ移した。
- `map_home`の睡眠、作業台、倉庫と、`map_village`の建築窓口をObject Layerへ移した。
- なごみ亭、商店、鉄火堂、診療所、川、神社、神社参道、古池、迷いの森、淀みの大樹の操作設備もObject Layerへ移した。
- 全15設備の座標はTiled JSONのみを情報源とし、Scene内の座標フォールバックを削除した。
- 全設備IDがいずれか1マップへ重複なく配置されていることを自動検査するようにした。
- 漁具小屋の源三と村長宅の宗一郎の基準位置を`NpcSpawns`へ移し、日課時間中はマップ側の配置を使用するようにした。
- 森入口の章イベント領域と、迷いの森の手掛かり3点をObject Layerへ移した。
- 採取物と探索物のScene内座標フォールバックを削除し、配置の情報源をTiled JSONへ統一した。
- 採取物のアイテム、数量、必要道具、イベントID、設備表示情報、同一レイヤー内の名前重複を自動検査するようにした。

全16マップを `art-ready` とする。この段階の `art-ready` は「正式アートを差し込めるデータ構造と配置責務が整った」ことを表し、正式タイル・建物・植生・アニメーションが完成した意味ではない。

### 2026-08-12：主人公宅敷地フェーズ

- `map_homestead`を追加した。
- ニューゲームの開始地点を祖父宅の屋外敷地へ移した。
- 村南側と主人公宅敷地、主人公宅内装を双方向接続した。
- 家から出た際は玄関前、村から戻った際は敷地北側の道へ配置する。
- 畑と第1章用の採取物を村中央から主人公宅敷地へ移した。
- 既存セーブは保存済みのMap IDと座標から再開できる互換性を維持した。
- 全Transitionの接続先Spawnと、第1～3章の通し進行を自動テストで確認した。

現段階の地面と建物は引き続き仮描画であり、正式タイルセットと装飾制作は別工程とする。

### 2026-08-12：村生活施設フェーズ

- `map_nagomi`、`map_shop`、`map_forge`を追加した。
- 村中央から、なごみ亭、商店、鉄火堂へ出入りできるようにした。
- 料理操作をなごみ亭、種の購入操作を商店へ移した。
- 楓と鉄斎を営業時間中の勤務先へ配置した。
- 朝のしきを主人公宅敷地の畑へ配置し、日中は村中央へ移動させた。
- 施設を出た際は、それぞれの建物正面へ復帰する。
- 全施設Transition、NPCスケジュール、第1～3章の通し進行を自動テストで確認した。

鉄火堂の神具強化・加工UI、各施設の正式な内装タイルと設備アニメーションは後続工程で実装する。

## マップ完成判定

- 第1～3章の全必須地点へ、進行条件に従って移動できる。
- すべてのTransitionに有効な接続先Spawnがある。
- 主人公宅を出た際など、各入口の正面へ自然に復帰する。
- 村の生活導線と外部の危険区域が視覚的に区別できる。

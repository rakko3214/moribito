# First Playable マップ実装進捗

## 2026-08-26：正式地形アセット導入開始

- 主人公宅敷地用のシームレスな草地ピクセルテクスチャを生成し、プロジェクト内アセットとして保存した。
- マップ別の地形テクスチャ登録をコード上で一元管理し、主人公宅敷地へタイル描画した。
- テクスチャ未登録・読み込み失敗時は従来の背景色へ戻るため、他15マップの表示を壊さず段階移行できる。
- 当たり判定、農地、採取物、設備、Transitionは従来のTiled配置を維持し、見た目だけを独立して更新できる構成にした。
- 主人公宅、伐採可能な木、採掘可能な岩を透明背景の個別ピクセルアセットとして追加した。
- 主人公宅に初期宅、修繕・増築後、最終増築後の3種類の外観を用意し、大工への2回の依頼で順番に切り替わるようにした。
- 主人公宅は固定位置のまま更新し、鶏小屋などの自由配置建築とは分離した。
- 室内も家の段階に応じて床面、増築部屋、縁側、最終段階の特別室が切り替わるモック表示に対応した。
- 家は既存の建物当たり判定と玄関Transitionへ、木・岩は`GatheringNodes`の座標へ合わせて表示する。
- 木・岩は採取状態と表示状態が同期し、破壊後およびセーブ復元後に従来どおり非表示になる。
- 390×844のスマートフォン表示で、玄関、採取物、主人公、操作UIの視認性とブラウザエラーがないことを確認した。

この素材は正式ビジュアル制作の第1版である。道、畑の縁、水場、薬草、主人公・NPCなどの個別スプライトは後続フェーズで追加する。

## 2026-08-25：Tiled Object Layer移行基盤

- 全16マップのファイル、章、用途、移行順、必須Object Layerをマニフェスト化した。
- マップ単体と全マップ接続を検査する自動バリデーションを追加した。
- 主人公宅敷地は採取物、農地48区画、家畜設備、農業イベント領域をマップデータから生成する。
- 主人公宅内は睡眠、作業台、倉庫を、村中央は建築依頼地点をマップデータから生成する。
- 全16マップが配置責務を持つ `art-ready` 段階へ到達した。
- 料理、釣り、調合、鍛冶、買い物、奉納、通常戦、章ボス、木霊イベントを含む全15設備の座標をTiled JSONへ統一した。
- 漁具小屋・村長宅の主要NPC位置、森入口の章イベント領域、迷いの森の手掛かり3点をTiled JSONへ移した。
- 正式アート導入前のため、`art-ready`は視覚的な完成を意味しない。
- 正式な敵座標はマップアートと回避空間が確定してから調整するため、現段階では固定しない。

細分テストでは、Object Layer解析、農地区画生成、必須プロパティ、重複ID・名前、範囲外配置、Transition・Spawn整合性を検証する。

- 川と漁具小屋を相互接続し、釣り操作を川の釣り場へ移した。
- 調合操作を診療所内へ移した。
- 源三を朝の川、昼の漁具小屋、夕方の川へ配置した。
- 宗玄を薬草採取、診療所、往診、調合の時間帯に合わせて配置した。
- 宗一郎を日中の村長宅と夕方の村内へ配置した。
- 全Transitionの接続先Spawn、NPC勤務先、既存章進行を自動テスト対象に含めた。

現段階の4マップは機能と導線を検証する仮描画であり、正式な地形・建物・内装・水面演出は後続工程で制作する。

## 2026-08-12：第3章森林分割フェーズ

- 既存の`map_forest`を森の入口として残し、`map_forest_depths`と`map_yodomi_grove`を追加した。

- 陽太の痕跡3点と木霊との遭遇を迷いの森へ移した。
- 淀みの大樹戦と安全地帯判定を専用の木立へ移した。

森林3マップは探索とボス導線を検証する仮描画であり、正式な迷路、植生、痕跡、浄化前後差分は後続工程で制作する。

## 2026-08-12：マップ視認性・状態差分フェーズ

- 主人公宅敷地、村、川、神社参道、神社、森の入口、迷いの森へ仮ランドマーク表示を追加した。
- 村では広場、診療所、村長宅の位置を画面上で識別できるようにした。
- 川では水面と釣り場、神社参道では参道の方向を識別できるようにした。
- 化け蛙浄化後は「穢れた古池」から「澄んだ古池」へ、その場で色と表示が変化する。
- 淀みの大樹浄化後は「淀みの大樹」から「光の戻った木立」へ、その場で色と表示が変化する。
- 状態差分はイベントフラグから復元されるため、セーブ・ロード後も維持する。

追加した表現は正式アートではなく、マップの役割と環境変化を確認するためのコード描画である。

## 2026-08-13：移動案内UIフェーズ

- 全16マップの正式な画面表示名をコード側で統一した。
- 各出口へ「→ 行き先」のラベルを表示し、移動前に接続先を確認できるようにした。

- スマートフォンでは目的、目的地、依頼だけを簡潔に表示する。
- 第1章、第2章、第3章の専用戦闘・探索マップを目的地として案内する自動テストを追加した。

## 2026-08-13：進行ゲートフェーズ

- 古池は村人依頼、奉納、神社への報告を終えるまで進入できないようにした。
- 森の入口は第2章終了後、陽太と話してから進入できるようにした。
- 迷いの森は森の入口を確認した後に進入できるようにした。
- 淀みの大樹は痕跡探索と木霊遭遇を終えるまで進入できないようにした。
- 未解放の出口へ触れた場合は理由と次の行動を表示し、入口から安全な方向へ戻す。
- 村の生活施設や既に解放済みの場所は制限しない。

## 2026-08-13：簡易地図・経路案内フェーズ

- スマートフォンとPCの画面上部へ「地図」ボタンを追加した。
- 地図には現在地、章目的地、最短経路、現在地から利用できる出口を表示する。
- 主人公宅から古池、神社から診療所など、複数マップをまたぐ最短経路を自動計算する。
- 地図表示中は主人公の移動とフィールド操作を停止し、誤操作を防止する。
- 画面サイズ変更時に地図パネルの幅、高さ、折り返し位置を再調整する。

## 2026-08-13：目的地出口マーカー・到着案内フェーズ

- 現在地から章目的地へ向かう最短経路の「次の出口」を自動判定する。
- 次に使う出口だけを緑色、太枠、点滅表示にし、「目的地」ラベルを付ける。
- 目的地と関係のない出口は従来の色と大きさを維持する。
- マップ移動後に現在地と次に向かう方面を短時間表示する。
- 目的地へ着いた場合は「目的地に到着しました」と表示する。
- 現在地が目的地の場合、不要な出口強調は行わない。

## 2026-08-13：村人・施設案内フェーズ

- 簡易地図へ現在地にいる村人を表示する。

- 勤務時間外の人物は位置を表示せず、全員不在の場合は「勤務時間外」と表示する。
- なごみ亭、万屋、鍛冶屋、診療所、村長宅、漁具小屋の営業時間を設定する。
- 現在時刻に営業している施設だけを簡易地図へ表示する。
- 日課配置、施設営業時間、地図表示の整合性を自動テストへ追加する。

# 河童

Status: Approved
Last updated: 2026-08-04

## コンセプト

「構ってほしい、寂しがり屋のやんちゃ坊主」。

悪意のある妖怪ではない。忘れられることを恐れ、自分の存在を知ってほしいという気持ちから、村人の気を引くいたずらを繰り返している。

心のテーマは「承認」。友好度イベントでは、自分を見てもらうためのいたずらから、誰かを笑顔にする喜びへ変化する過程を描く。

## デザイン

コンセプトは「かわいいマスコット河童」。

- 丸い体
- 緑色
- 小さな甲羅
- 丸い目
- 短い手足
- 撫でたくなる親しみやすい造形

## メインストーリーと加入

### 初登場

村で、きゅうり泥棒、洗濯物を流す、水路を勝手に開けるといったいたずらが続き、村人は河童へ怒っている。

主人公が川へ向かうと、河童は木陰から村人の様子を見て笑っている。主人公が理由を尋ねると、河童は「みんな、おいらを見てる！」「忘れてない！」と答える。主人公は、行動の根に悪意ではなく孤独があることへ気づく。

### 転機

主人公は河童と子どもたちが遊ぶ機会を作る。親から河童へ近づかないよう言われている子どもたちには迷いがあるが、主人公の橋渡しによって少しずつ一緒に遊べるようになる。

### 仲間加入

いたずらをしなくても皆が笑ってくれることを知った河童は、自分も村を守ると決め、主要妖怪として正式に仲間となる。友好度Rank ★1と妖怪札「水流」を解放する。

## 友好度イベント

テーマは「人を笑顔にする喜び」。自分が楽しむだけの段階から、周囲を楽しませる存在へ成長する。

### Rank ★1：きゅうり作り

主人公と畑できゅうりを育て、収穫したきゅうりを一緒に食べる。

### Rank ★2：川遊び

主人公と魚捕り競争や水遊びをする。

### Rank ★3：釣り大会

子どもたちとの釣り大会を行う。河童は自分が勝つことだけでなく、皆を楽しませるために頑張る。

### Rank ★4：祭りの準備

主人公や村人と協力し、村祭りの水遊び会場を作る。

### Rank ★5：水遊び大会

河童が中心となって水遊び大会を開催し、村人を笑顔にする。子どもたちから次も遊ぼうと呼びかけられ、村の大人から感謝ときゅうりを受け取る。河童は「いたずらじゃなくても、みんな笑ってくれる」と心から喜ぶ。

## 妖怪札「水流」

属性は水、主役割は攻撃と妨害とする。Rankごとに別の技を増やさず、一つの水流を完成形へ育てる。

| Rank | 強化内容 |
|---|---|
| ★1 | 小さな水弾を1発発射する |
| ★2 | 貫通性能を追加する |
| ★3 | 水弾のサイズと速度を強化する |
| ★4 | 着弾時に水しぶきを発生させる |
| ★5 | 大きな渦潮となり、周囲へ広がる |

Rank ★4の減速効果はレビュー上の提案に留まるため、正式採用せず未決定とする。

## 生活・フィールドでの役割

- 川、水路、池の近くを主な生活圏とする。
- 農業では水やりと水路管理を支援する。
- 釣り、魚捕り、川の採取へ関わる。
- Rank上昇に応じて、子どもや村人と遊ぶ日常行動を増やす。
- Rank ★5後は、水遊びや釣りを自分から企画する姿を見せる。

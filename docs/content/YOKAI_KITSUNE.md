# 妖狐

Status: Approved  
Last updated: 2026-08-04

## 基本設定

- 主要妖怪、善良妖怪。
- 普段は子狐の姿で暮らす。
- 子どもっぽく、好奇心旺盛で少しいたずら好き。
- 初対面では人間への警戒心が強いが、主人公との交流を通して徐々に懐く。
- 人型は友好度Rank ★5で初めて主人公へ見せる。
- ★5以降も通常時は子狐の姿とし、人型は季節イベント、特別イベント、エンディングなどに限定する。
- 人型の公開は恋愛表現ではなく、主人公を心から信頼した証として扱う。

## メインストーリーと加入

### 初登場

村人から畑荒らしの犯人だと誤解されている。実際には、村や畑へ近づく穢れ妖怪を人知れず追い払っている。主人公はその事実を目撃する。

### 信頼の形成

妖狐が主人公を助ける場面を重ね、主人公も村人の誤解を解くために行動する。妖狐は少しずつ主人公を信用する。

### 仲間加入

主人公に助けられた妖狐が、頭を擦り寄せて信頼を示す。ここで主要妖怪として正式に仲間となり、友好度Rank ★1と妖怪札「狐火」を解放する。

## 友好度イベント

テーマは「人を信じられるようになること」。過去の説明を中心にせず、仲間になった後に主人公や村人との絆が育つ過程を描く。

### Rank ★1：料理

主人公から料理を受け取り、食事を通して少しずつ距離を縮める。

### Rank ★2：村の散歩

主人公と村を散歩する。木の実、小川の魚、落ち葉、鳥などへ子どもらしい興味を示した後、遠くで遊ぶ子どもたちを羨ましそうに見つめる。

### Rank ★3：子どもたちとの交流

主人公が子どもたちへ「危ない妖怪ではない」と伝える。子どもたちも迷いながら妖狐へ近づき、やがて一緒に遊ぶ。妖狐は初めて心から笑う。

### Rank ★4：守りたい気持ち

主人公を守るため、自ら危険へ飛び込む。人を避けていた妖狐に、主人公を守りたいという意志が芽生える。

### Rank ★5：信頼の証

夜の神社で、妖狐が主人公だけに本当の人型を見せる。人型は恋愛的な報酬ではなく、誰にも見せてこなかった姿を託す信頼の証とする。

## 妖怪札「狐火」

属性は火、主役割は攻撃とする。Rankごとに別の技を追加せず、一つの狐火を完成形へ育てる。

| Rank | 強化内容 |
|---|---|
| ★1 | 小さな狐火を1発発射する |
| ★2 | 敵を追う追尾性能を追加する |
| ★3 | 火球サイズと攻撃範囲を強化する |
| ★4 | 命中した敵へ燃焼を付与する |
| ★5 | 着弾時に爆発し、炎が周囲へ飛び散る |

威力、消費霊力、クールタイム、燃焼時間などの具体値は戦闘バランス調整で決定する。

## フィールド演出

友好度Rankに応じて、普段の距離感と行動を変化させる。

| 状態 | 主な行動 |
|---|---|
| 加入直後 | 近づくと距離を取り、一定以上は近寄らない |
| ★1 | 主人公宅の前で待つ |
| ★2 | 家へ遊びに来る、近くで昼寝する |
| ★3 | 撫でられる、主人公の後をついて歩く |
| ★4 | 主人公の肩へ乗る、夜に家へ遊びに来る |
| ★5 | 人型を特別イベントでのみ見せる |

# 村人一覧

Status: Partially Approved
Last updated: 2026-08-06

## 方針

- 約25人を目安に、村の暮らしと物語に必要な人物を配置する。
- 原則として友好度、日常スケジュール、個人イベントを持たせる。しきは専用サブイベントを設けず、メイン・季節・村イベントで関係を描く。
- 友好度ポイントは事前に蓄積できるが、Rank上限とRankイベントはメインストーリー進行に応じて解放する。
- 生活システムの案内役は、担当機能と物語上の役割を両立させる。

## 個別設計済み

### 宗一郎

- 58歳、男性、結の村の村長。
- 20年前に妻と幼い娘を失い、神主の偽りによって妖怪を憎んでいる。
- 村の復興計画、大型依頼、祭り、共存度の人間側案内を担当する。
- 詳細は [`VILLAGER_SOICHIRO.md`](VILLAGER_SOICHIRO.md) を参照。

### しき

- 20歳の男性で、男性主人公と同年代の幼なじみ。楓の息子。
- 農業と序盤生活の案内役を担い、専用サブイベントは設けない。
- 詳細は [`VILLAGER_SHIKI.md`](VILLAGER_SHIKI.md) を参照。

### 楓

- 38歳、女性、食事処「なごみ亭」店主。
- 料理チュートリアルを担当し、なごみ亭を人と妖怪の共存を象徴する場所とする。
- 詳細は [`VILLAGER_KAEDE.md`](VILLAGER_KAEDE.md) を参照。

### 源次

- 38歳、男性、行商人・雑貨屋。
- 外の世界と村をつなぎ、人と妖怪の共存を他地域へ伝える。
- 詳細は [`VILLAGER_GENJI.md`](VILLAGER_GENJI.md) を参照。

### 源三

- 56歳、男性、漁師。
- 釣りの案内役であり、川の異変から河童の物語へつなぐ。
- 詳細は [`VILLAGER_GENZO.md`](VILLAGER_GENZO.md) を参照。

### 鉄斎

- 48歳、男性、鍛冶屋「鉄火堂」の職人。
- 神具・妖怪札の強化、鉱石の精錬、素材加工、採掘道具を担当する。
- 詳細は [`VILLAGER_TESSAI.md`](VILLAGER_TESSAI.md) を参照。

### 樹

- 41歳、男性、大工。
- 主人公宅、倉庫、家具、橋、階段、村施設の修復を担当する。
- 詳細は [`VILLAGER_ITSUKI.md`](VILLAGER_ITSUKI.md) を参照。

### 宗玄

- 62歳、男性、薬師。
- 人と妖怪の命を分け隔てず、治療と薬の調合を担う。
- 調合担当として挙がった「蓮」との関係は未決定。
- 詳細は [`VILLAGER_SOGEN.md`](VILLAGER_SOGEN.md) を参照。

## 伏線担当候補

- 鉄斎：祖父との約束により秘密を話せない。
- 薬師：穢れを病気に近い現象と考えて研究する。
- 少年：村人より早く妖怪を認識している可能性がある。
- 老女：昔話の形で真実を伝える。
- 巫女：神主を尊敬し、真相判明時に大きく揺れる。

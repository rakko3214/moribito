# しき（主人公の親友）

Status: Approved
Last updated: 2026-08-05

## 基本設定

- 正式表記は、ひらがなの「しき」。
- 20歳の男性で、男性主人公と同年代の幼なじみ。
- 母は楓、父は故人。楓と共になごみ亭を支えている。
- 恋愛対象にはせず、最後まで主人公の味方となる。
- 明るく人懐っこい世話焼きで、行動力がある。村中の人と仲が良く、頼まれると断れない。主人公の前では少し子どもっぽい。

## 役割

- 主人公の親友
- ゲーム開始直後の生活ナビゲーター
- 農業チュートリアル担当
- メインストーリーで主人公を支える存在

村、祖父の家、農業、採取、納品、村人への挨拶を案内し、必要な人物との会話へ自然につなげる。初戦闘後はメイン進行の案内役を神主へ引き継ぐが、生活面では引き続き主人公を支える。

## なごみ亭での仕事

料理人ではなく、配膳、接客、買い出し、配達、食材運搬、畑仕事を担当する。なごみ亭で使う野菜の一部も育てている。

## 農業経験

しきは農家ではない。幼少期に主人公と共に祖父の畑仕事を手伝い、土の耕し方、種まき、水やりなどの基本を教わった。なごみ亭用の野菜も育てているため、初心者へ農業を教えられる知識を持つ。

## デザイン

- 少し日に焼けた肌
- 茶色の短髪
- 笑顔が多い
- 動きやすい和風作業着と腕まくり
- 草履または地下足袋

「村の人気者」「元気なお兄ちゃん」と一目で分かるデザインとする。

## 戦闘

戦闘には参加しない。神具、結界、妖怪札を使用せず、主人公へ追従する戦闘NPCにもならない。最後まで村と生活面から主人公を支える。

## イベント方針

専用の友好度サブイベントは設けない。代わりに、次の場面へ自然に登場させて存在感と関係の変化を描く。

- メインストーリー
- 季節イベント
- 村イベント

序盤は妖怪を恐れ、主人公の友好化へ反対することもある。終盤では主人公を最初に支持する村人となる。

## 主な物語上の変化

- 第1章：主人公を迎え、村、家、畑、農業、採取、納品を案内する。
- 中盤：妖怪を恐れ、主人公が妖怪へ近づくことに反対して衝突する。
- 終盤：主人公の行動を理解し、村人の中で最初に主人公を支持する。
- 最終章：主人公を送り出し、帰還後は幼少期のように笑い合う日常へ戻る。

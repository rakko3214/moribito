# 妖怪図鑑・コンテンツ設計

Status: Draft  
Last updated: 2026-07-28

## 想定構成

- 善良妖怪：約12体
- 中立妖怪：約8体
- 固有穢れ妖怪：約10体
- 穢れ化バリエーション：約10～15体
- 図鑑登録：約40～45枠

## 分類ルール

### 善良妖怪

人間との共存を望む、または人知れず自然や村を守る。友好化後は生活を支援する。

### 中立妖怪

人間を信用していない。サブクエストや行動で関係が変化する。

### 穢れ化妖怪

善良・中立妖怪が穢れに侵された形態。浄化によって元に戻せる。

### 固有穢れ妖怪

穢れそのものから生まれた敵性存在。浄化による救済はできず、討伐する。

## 図鑑の進行

以下の行動で記録が増える。

- 出会う
- 穢れ化形態を見る
- 浄化する
- 個別クエストを完了する
- 友情を深める

単なる発見図鑑ではなく、妖怪を理解する図鑑とする。

## 暫定個体

### 木霊

- 分類：善良
- 生息地：森
- 性格：穏やかで臆病
- 役割：森の守護
- 支援：森の採取、作物成長または収穫量
- 友好化：森の穢れを浄化
- 穢れ化候補：穢れ木霊

### 河童

- 分類：善良
- 生息地：川・池
- 性格：いたずら好き、面倒見がよい
- 支援：水やり、田んぼ、釣り、川の清掃
- 友好化：川の浄化と水路修復
- 好物候補：きゅうりを使った料理
- 穢れ化候補：穢れ河童

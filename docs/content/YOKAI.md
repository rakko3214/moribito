# 妖怪図鑑・コンテンツ設計

Status: Partially Approved
Last updated: 2026-07-31

## 全体構成

| 区分 | 人数 | 主な役割 |
|---|---:|---|
| 主要妖怪 | 8体 | 本編、生活機能、友好度Rank、妖怪札 |
| 準主要妖怪 | 12体 | 地域イベント、サブクエスト、妖怪社会 |
| 神格妖怪 | 5体前後 | 中盤～終盤の重要存在、地域ボス |
| 不可逆穢れ妖怪 | 5～8体 | 物語上の討伐対象 |
| 穢れ化差分 | 10～15体 | 浄化対象、戦闘差分 |

妖怪帳総数はページ・登録枠の目標であり、全員を同じ密度で制作することを意味しない。

## 生態・立場による分類

### 自然妖怪

森、川、山など自然環境と結びつき、その土地を守る妖怪。河童、木霊、妖狐、天狗、白蛇などを含む。

### 里妖怪

家や村の近くで人間の生活を支えてきた妖怪。座敷童子、一反木綿、提灯お化け、ぬりかべなどを候補とする。

### 神格妖怪

強大な霊力を持ち、地域や自然現象を守護する存在。通常は人前へ姿を見せず、主人公が本来の結師として認められる過程で関わる。大天狗、九尾、龍、大蛇などを候補とする。

## 関係・状態による分類

### 善良妖怪

人間との共存を望む、または人知れず自然や村を守る。友好化後は生活を支援する。

### 中立妖怪

人間を信用していない。サブクエストや行動で関係が変化する。

### 穢れ化妖怪

善良・中立妖怪が穢れに侵された形態。浄化によって元に戻せる。

### 不可逆穢れ妖怪

穢れに完全に飲まれ、元の人格と状態を回復できなくなった存在。浄化による救済はできず、被害を止めるため討伐する。

「穢れが無から妖怪を生み出す」のではなく、既存の妖怪が不可逆な段階まで侵された状態とする。

## 物語進行による穢れの強化

### 前半

- 天狗など自然妖怪の穢れ化が中心。
- 基本的に浄化可能。
- 妖怪と穢れの違いをプレイヤーが学ぶ。

### 中盤

- 神格妖怪も穢れに侵され始める。
- 浄化には専用クエスト、特定の料理、土地の修復などの条件が必要になる。
- 救済の難度が上がる。

### 終盤

- 神格妖怪の穢れ化が主要な脅威となる。
- 初代神主が穢れを集め、増幅し、操っている事実が判明する。
- 不可逆穢れ妖怪も登場し、浄化ではなく討伐が必要になる。

浄化できない個体は物語上の重い出来事として扱い、通常戦闘で大量に消費しない。

## 妖怪の暮らし

妖怪にも人間と共通する生活と、地域ごとの文化がある。

- 畑や水路を手入れする
- 木の実、薬草、素材を集める
- 家族や仲間を支える
- 病気や穢れを看病する
- 祭りや共同作業を行う

第4～6章では、この暮らしを見せることで主人公とプレイヤーの認識を変化させる。

## 主要妖怪

主要妖怪は次の8体を正式採用する。神格妖怪は別の終盤枠とする。

| 妖怪 | 主な担当 | 位置づけ |
|---|---|---|
| 座敷童子 | 物語・記憶・家 | 最初から味方だった特別枠 |
| 河童 | 水路・農業・釣り | 水辺の生活支援 |
| 天狗 | 山・移動・ファストトラベル | 高所探索と山の案内 |
| 妖狐 | 商売・情報・神社・幻術 | 神社・古社と情報網 |
| 木霊 | 森・採集・自然・植林 | 森林資源と自然回復 |
| 鬼 | 鍛冶・採掘 | 鉱石と加工 |
| 白蛇 | 薬・回復・浄化 | 神社や畑の浄化 |
| 雪女 | 保存・寒冷地 | 保存技術と寒冷地域 |
| 神格妖怪（別枠） | 終盤支援 | 個体数は未決定 |

座敷童子には通常の加入イベントを設けない。主人公が忘れているだけで最初から味方であり、物語後半に「仲間になった」ではなく「帰ってきた」と感じられる形で行動を共にする。

妖怪は原則として常時同行する戦闘要員にせず、各地域で暮らしながら生活、探索、物語、必要な戦闘を相互に支援する存在とする。

主要妖怪は全員、固有ストーリー、友好度Rank、Rankイベント、妖怪札、固有会話、立ち絵、フィールドスプライト、妖怪帳専用ページを持つ。

## 神格妖怪

- 4～6体、基準5体前後とする。
- 中盤～終盤の地域ボス、浄化対象、物語上の重要存在として扱う。
- 基本的には通常の仲間・妖怪札対象としない。
- 個体に応じて通常の友好度システムとは別の承認・協力条件を設定できる。
- 神格穢れ化を終盤のボス級形態として使用できる。

## 図鑑の進行

以下の行動で記録が増える。

- 出会う
- 穢れ化形態を見る
- 浄化する
- 個別クエストを完了する
- 友情を深める

単なる発見図鑑ではなく、妖怪を理解する図鑑とする。

妖怪帳では、遭遇時の第一印象から友好度Rank ★5の完全情報まで段階的に記録を解放する。詳細は [`YOKAI_BOOK.md`](YOKAI_BOOK.md) を参照。

## 個別設計着手済み

### 木霊

- 分類：善良
- 生息地：森
- 性格：穏やかで臆病
- 役割：森の守護
- 支援：森の採取、作物成長または収穫量
- 友好化：森の穢れを浄化
- 穢れ化候補：穢れ木霊

### 河童

- 分類：善良
- 生息地：川・池
- 性格：いたずら好き、面倒見がよい
- 支援：水やり、田んぼ、釣り、川の清掃
- 友好化：川の浄化と水路修復
- 好物候補：きゅうりを使った料理
- 穢れ化候補：穢れ河童

木霊と河童以外の正式採用個体は、共通テンプレートを用いて順次個別設計する。未採用妖怪を追加する場合は、既存20体との地域・生活機能・妖怪札の役割重複を確認する。

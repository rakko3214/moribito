# 化け蛙

Status: Approved
Last updated: 2026-08-07

## コンセプト

「無口でのんびりした古池の住人」。

古池と地下水脈の周辺に昔から棲む自然系妖怪。人間を積極的に襲わず、水辺の生き物と共存し、結果として周辺の水環境を守ってきた。

第2章では、流れ込む穢れを自ら取り込み続けた末に暴走し、最初の本格的な章ボス「穢れ化・化け蛙」として登場する。

## 基本プロフィール

| 項目 | 内容 |
|---|---|
| 分類 | 準主要妖怪、自然妖怪、一時穢れ化妖怪 |
| 生息地 | 古池、水路、地下水脈周辺 |
| 属性・モチーフ | 水、泥、雨、蛙、蓮 |
| 名称 | 化け蛙。個体名は設定しない |
| 性格 | おっとり、無口、我慢強い、警戒心が強い、食いしん坊 |
| 人間への態度 | 積極的には襲わないが、距離を取る |

## 対応システム

化け蛙は主要妖怪ではなく、次の対象外とする。

- 友好度と友好度Rank
- プレゼント
- 個別友好イベント
- 妖怪札の獲得

妖怪帳には登録する。浄化後のページには、姿、種族、発見場所、浄化記録、簡単な生態を表示し、友好度や妖怪札関連の項目は表示しない。

## 通常時デザイン

スターデューバレーライクな2Dドット表現を前提とする。

- 丸く大きめの蛙型妖怪
- 緑から深緑の体色
- 大きな目と少し眠そうな表情
- 背中の苔、水草、小さな蓮の葉
- 通常の蛙より大きいが、穢れ状態より小さい

浄化後に「本当に危険な妖怪だったのか」と疑問を持てるよう、過度に恐ろしい造形にはしない。

## 穢れ状態デザイン

- 大量の穢れに覆われ、通常時の約1.5～2倍に見える
- 黒紫色の泥状の穢れが身体を覆う
- 目が赤紫色になる
- 背中の苔や蓮が枯れている
- 身体から黒い液体と穢れが漏れる

身体そのものが巨大化したのではなく、取り込んだ穢れが外殻のように覆っている。浄化時に外殻が剥がれ、本来の小さな姿へ戻る。

## 穢れ化した原因

古池の地下水脈へ不自然な穢れが流れ込む。化け蛙は水辺と村へ広がるのを抑えるため、自身の身体へ穢れを取り込み続けるが、許容量を超えて正気を失う。

```text
地下水脈へ穢れが流入
  ↓
化け蛙が穢れを取り込む
  ↓
許容量を超えて穢れ化
  ↓
古池と水路周辺で暴走
```

化け蛙自身は穢れの発生源ではない。水脈へ流入した原因は第2章では明かさず、後の物語への疑問として残す。

## 第2章での情報開示

神主は「古池に棲む妖怪によって穢れが広がっている」と説明する。浄化後も真相は直接説明せず、化け蛙が主人公を攻撃せず怯えて池へ逃げることで、「妖怪そのものが悪いとは限らない」という小さな違和感だけを残す。

神主は「妖怪の振る舞いに惑わされてはいけません」と説明し、序盤の妖怪観を維持する。

## 章ボス戦

戦闘場所は「古池・穢れた水辺」。円形に近い広めのフィールドへ古池、浅瀬、岩、壊れた祠、水路を配置する。チュートリアルボスのため、移動を大きく妨げる障害物は少なくする。

### 第1フェーズ：移動回避

| 攻撃 | 予告と対応 |
|---|---|
| 舌突き | 直線予告。左右へ回避。結界でも防御可能 |
| 飛び掛かり | 円形の着地点予告。移動回避が基本 |
| 3方向水弾 | 遅い水弾の間を移動。結界でも防御可能 |

### 第2フェーズ：攻撃種別の判断

| 攻撃 | 予告と対応 |
|---|---|
| 穢れ沼 | 黒紫色の地面攻撃。結界貫通、移動回避必須 |
| 呪いの舌薙ぎ | 紫色の扇形予告。結界貫通、移動回避必須 |
| 回転水弾 | 弾の間を移動。結界可能だが回避推奨 |

穢れ沼は戦場全体を覆わず、踏み続けると呪いの危険が発生する。通常の舌攻撃と呪いの舌薙ぎは、色、音、予告形状を明確に変える。

### 第3フェーズ：結界の使用判断

大技「濁流大波」を使用する。

1. 化け蛙が池中央へ移動する。
2. 大量の水と穢れを吸い込み、長い予備動作と専用警告音を出す。
3. フィールド全体へ濁流を発生させる。
4. プレイヤーは結界を張りながら耐える。
5. 発動後、化け蛙が疲労し、最大の攻撃機会が生まれる。

濁流大波は通常移動では回避不能で、結界必須とする。第2章では結界必須攻撃をこの大技へ絞り、結界を常用せず大技へ残すルールを定着させる。

結界なしで受けた場合は護身札1枚を失い、大きく吹き飛ばされ、短時間行動不能になる。即死や護身札の複数枚消費にはしない。

## 戦闘言語

| 表現 | 基本対応 |
|---|---|
| 白・青系の通常攻撃 | 移動回避推奨、緊急時は結界可能 |
| 黒・紫系の穢れ・呪い攻撃 | 結界貫通、移動回避必須 |
| 専用の全画面予告 | 回避不能、結界必須 |

この視覚・音響ルールを後半の戦闘へ発展させる。

## 撃破と浄化

神具で化け蛙を殺すのではなく、身体を覆う穢れを削る。

```text
神具で穢れを削る
  ↓
化け蛙がダウン
  ↓
浄化可能状態
  ↓
主人公が最終浄化
  ↓
穢れの外殻が剥がれる
  ↓
本来の化け蛙へ戻る
```

第2章最初の本格的なボス浄化であるため、最終浄化に複雑な追加操作は要求しない。

## 浄化後

化け蛙は主人公へ怯えた様子を見せ、攻撃せず古池へ逃げる。真相を説明する台詞は入れない。

後日、古池では通常状態の化け蛙を遠景で見られる場合がある。蓮の葉や岩の上で休み、主人公が近づくと池へ逃げる程度の環境演出とする。友好度、クエスト、妖怪札には接続しない。

## 浄化報酬

- 霊力
- 浄化された水系素材
- 神具の初期強化素材
- 調合用素材

穢れそのものは取得しない。素材名、取得数、強化値はアイテム・バランス設計時に確定する。

## 未確定

- 攻撃間隔、弾速、予告時間、フェーズ移行値
- 結界消費量、行動不能時間、ボス耐久値
- 戦闘共通の敗北、セーブ、再挑戦仕様

これらは第2章固有仕様にせず、実装とプレイテスト、共通システム設計で決定する。
